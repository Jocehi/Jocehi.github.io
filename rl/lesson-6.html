第 6 课 · SARSA 与 Expected SARSA

SARSA & Expected SARSA · RL 算法每日精讲 · 2026-11-20 · 值函数方法 · 入门 · 约 30 分钟

前置知识：Q-Learning

按真实执行的动作学习，期望版则对下一步动作求平均。

讲解视频 · SARSA 与 Expected SARSA · 7 分 04 秒

① 问题设定

在机器人行走、游戏操作与序列推荐等控制任务中，智能体需要在与环境反复交互的过程中学习一个好策略。环境通常建模为马尔可夫决策过程：智能体在状态 $s$ 下选择动作 $a$，得到奖励 $r$ 并转移到下一状态 $s'$，目标是最大化长期折扣回报，折扣因子为 $\gamma$。当环境模型未知、且无法像蒙特卡洛方法那样等到回合结束才学习时，智能体需要仅凭一步转移就更新价值并改进策略。SARSA 与 Expected SARSA 正是为此设计的同策略时序差分控制算法：它们维护动作价值函数 $Q(s, a)$，用当前策略实际产生或期望化的下一步价值作为学习目标，在交互中不断评估并改进同一策略。输入为交互得到的状态、动作与奖励序列，以及学习率 $\alpha$、折扣因子 $\gamma$ 与探索参数 $\epsilon$；输出为学到的动作价值函数 $Q(s, a)$ 与据此导出的贪心或 $\epsilon$-贪心策略 $\pi$。它们适用于模型未知、需要在线学习、且希望稳妥评估正在执行策略的场景，尤其适合动作执行代价高、不宜用未执行的最优动作冒进评估的任务。

② 核心思想
  • SARSA 是同策略方法：它用当前行为策略实际执行的下一步动作 $a'$ 对应的 $Q(s', a')$ 来构造学习目标，而不是取最大值，因此学到的是正在执行策略的价值。
  • 一次更新使用五元组 $S, A, R, S', A'$，即状态、动作、奖励、下一状态与下一动作，沿轨迹一步步做时序差分更新。
  • Expected SARSA 把下一步的单个采样价值换成在策略 $\pi(\cdot | s')$ 下的期望 $\sum_{a'} \pi(a' | s') Q(s', a')$，从而去掉对单个采样动作的依赖，方差更低。
  • 当行为策略是 $\epsilon$-贪心且 $\epsilon$ 逐渐减小时，SARSA 与 Expected SARSA 都能收敛到最优策略；在固定 $\epsilon$ 下，它们收敛到对应 $\epsilon$-贪心策略的价值。
  • Expected SARSA 在确定性策略下退化为 SARSA，在 $\epsilon$-贪心下则介于 SARSA 与 $Q$-学习之间：它保留同策略的稳妥性，又利用期望获得更好的稳定性。
③ 与已学方法对比

与 $Q$-学习相比，SARSA 的最大区别是同策略：$Q$-学习用 $\max_{a'} Q(s', a')$ 作为目标，学习最优动作价值，与行为策略无关，因而是异策略且更激进；SARSA 则用实际执行的 $a'$ 对应的 $Q(s', a')$ 作为目标，学到当前 $\epsilon$-贪心策略的价值，在悬崖行走等危险环境中更保守、更安全，代价是学习可能更慢，且最终性能受探索策略限制。与蒙特卡洛方法相比，两者都只需一步转移即可更新，无需等到回合结束，适用于连续任务，但引入了自举带来的偏差。与时序差分学习相比，SARSA 把状态价值推广到动作价值并直接用于控制。Expected SARSA 进一步用期望代替单次采样，在保持同策略性质的同时降低了方差，尤其在 $\epsilon$ 较大时更稳定，代价是每步需要对所有动作求期望，计算量随动作数增加而增大。

④ 学习流程
  1. 观察初始化并观察初始化 $Q(s, a)$，并设定学习率 $\alpha$、折扣因子 $\gamma$ 与探索参数 $\epsilon$，随后观测回合的初始状态 $s$ 作为当前状态。
  2. 决策按策略选动作根据当前 $Q(s, \cdot)$，按 $\epsilon$ 贪心策略为状态 $s$ 选择动作 $a$，以概率 $1-\epsilon$ 利用当前最优动作，并以概率 $\epsilon$ 探索其他动作。
  3. 行动执行动作在环境中执行动作 $a$，这是从状态 $s$ 到下一状态 $s'$ 的一步交互，执行结果将用于下一步的价值更新。
  4. 反馈观测奖励转移环境返回即时奖励 $r$ 与下一状态 $s'$，若 $s'$ 为终止状态，则令下一状态的价值为 $0$。
  5. 计算计算学习目标若用 SARSA，先按 $\epsilon$ 贪心策略在 $s'$ 处选出下一动作 $a'$，并以 $r + \gamma Q(s', a')$ 为学习目标。若用 Expected SARSA，则以 $\sum_{a'} \pi(a' \mid s') Q(s', a')$ 计算期望价值，并得到对应的学习目标 $r + \gamma \sum_{a'} \pi(a' \mid s') Q(s', a')$。
  6. 更新更新动作价值先计算时序差分误差，即学习目标减去当前估计 $Q(s, a)$，再用学习率 $\alpha$ 按更新规则修正 $Q(s, a)$。对 Expected SARSA，更新时把单个 $Q(s', a')$ 换成策略期望 $\sum_{a'} \pi(a' \mid s') Q(s', a')$。
  7. 循环转移并循环判断令 $s \leftarrow s'$，并把已选的 $a'$ 作为下一轮的动作 $a$，或在 Expected SARSA 中按策略重新选动作；若 $s$ 为终止状态则结束本回合，否则回到选动作步骤继续下一轮。
⑤ 关键公式

SARSA 更新规则

$$Q(s, a) \leftarrow Q(s, a) + \alpha\big[r + \gamma Q(s', a') - Q(s, a)\big]$$

该规则用一步真实奖励 $r$ 与折扣后的下一动作价值 $\gamma Q(s', a')$ 构成学习目标，再与当前估计 $Q(s, a)$ 相减得到时序差分误差。它不取 $\max_{a'} Q(s', a')$，而是用行为策略实际选出的 $a'$ 对应的价值，因此评估的是正在执行的策略。更新时用学习率 $\alpha$ 按误差方向修正 $Q(s, a)$，从而沿轨迹一步步改进价值估计。

  • $Q(s, a)$：状态 $s$ 下执行动作 $a$ 的动作价值估计
  • $\alpha$：学习率，控制每次更新向学习目标移动的步长
  • $r$：执行动作 $a$ 后环境给出的即时奖励
  • $\gamma$：折扣因子，衡量下一状态价值 $Q(s', a')$ 在当前更新中的权重
  • $Q(s', a')$：在下一状态 $s'$ 下实际执行下一动作 $a'$ 的动作价值，是同策略学习目标的关键部分

Expected SARSA 更新规则

$$Q(s, a) \leftarrow Q(s, a) + \alpha\left[r + \gamma \sum_{a'} \pi(a' \mid s') Q(s', a') - Q(s, a)\right]$$

该规则把 SARSA 学习目标中的单个采样价值 $Q(s', a')$ 换成策略期望 $\sum_{a'} \pi(a' \mid s') Q(s', a')$，从而不再依赖某一次偶然选出的 $a'$。由于期望对策略 $\pi$ 下所有可能动作加权平均，更新的方差更低，学习过程更稳定。它仍属于同策略方法，因为期望所用的 $\pi$ 就是当前正在执行的 $\epsilon$ 贪心策略。

  • $Q(s, a)$：状态 $s$ 下执行动作 $a$ 的动作价值估计
  • $\alpha$：学习率，控制每次更新向学习目标移动的步长
  • $r$：执行动作 $a$ 后环境给出的即时奖励
  • $\gamma$：折扣因子，衡量期望价值在当前更新中的权重
  • $\sum_{a'} \pi(a' \mid s') Q(s', a')$：在下一状态 $s'$ 下按策略 $\pi$ 对所有下一动作 $a'$ 的价值 $Q(s', a')$ 求期望，代替单个采样动作的价值
  • $\pi(a' \mid s')$：策略 $\pi$ 在状态 $s'$ 下选择动作 $a'$ 的概率

贪心探索策略

$$\pi(a \mid s) = \begin{cases} 1 - \epsilon + \frac{\epsilon}{|\mathcal{A}|}, & a = a^* \\ \frac{\epsilon}{|\mathcal{A}|}, & a \ne a^* \end{cases}$$

该策略以概率 $1 - \epsilon$ 利用当前最优动作 $a^*$，同时以概率 $\epsilon$ 在全部 $|\mathcal{A}|$ 个动作中均匀探索，因此贪心动作仍保留额外的探索概率 $\frac{\epsilon}{|\mathcal{A}|}$。当 $\epsilon$ 逐渐减小时，策略越来越贪心，SARSA 与 Expected SARSA 据此能逐步逼近最优策略；当 $\epsilon$ 固定时，它们收敛到对应 $\epsilon$ 贪心策略的价值。

  • $\pi(a \mid s)$：在状态 $s$ 下选择动作 $a$ 的概率
  • $\epsilon$：探索参数，取值在 $0$ 与 $1$ 之间，越大随机探索越多
  • $|\mathcal{A}|$：动作空间 $\mathcal{A}$ 中动作的总数
  • $a^*$：在状态 $s$ 下使 $Q(s, a)$ 最大的贪心动作
  • $a$：任意一个候选动作
⑥ 数学推导

  1. 第一步：从动作价值的定义出发，$Q^\pi(s, a)$ 表示从状态 $s$ 执行动作 $a$ 开始、之后按策略 $\pi$ 行动所能得到的期望折扣回报。

  2. 第二步：把第一步的回报按一步展开，当前奖励 $R_{t+1}$ 加上从下一状态 $S_{t+1}$ 继续行动的折扣回报，得到贝尔曼期望方程。

    $$Q^\pi(s, a) = \mathbb{E}_\pi\left[R_{t+1} + \gamma Q^\pi(S_{t+1}, A_{t+1}) \mid S_t = s, A_t = a\right]$$

  3. 第三步：由于环境模型未知，无法直接求上式中的期望，SARSA 用一次真实交互得到的 $r$、$s'$ 和实际选出的 $a'$ 代替期望中的对应量，构造一步采样目标。

    $$y = r + \gamma Q(s', a')$$

  4. 第四步：把采样目标 $y$ 与当前估计 $Q(s, a)$ 相减，得到时序差分误差，它衡量当前估计与一步真实经验之间的偏差。

    $$\delta = r + \gamma Q(s', a') - Q(s, a)$$

  5. 第五步：沿误差方向以学习率 $\alpha$ 修正估计，得到 SARSA 更新式；这里不用 $\max_{a'} Q(s', a')$，因为目标动作 $a'$ 是行为策略实际执行的动作。

    $$Q(s, a) \leftarrow Q(s, a) + \alpha \delta$$

  6. 第六步：Expected SARSA 进一步把单个 $Q(s', a')$ 换成策略期望，因为一次采样动作可能偶然偏高或偏低，而期望对所有 $a'$ 按 $\pi(a' \mid s')$ 加权，能去掉这部分采样噪声。

    $$\bar{Q}(s') = \sum_{a'} \pi(a' \mid s') Q(s', a')$$

  7. 第七步：把上式代入学习目标，就得到 Expected SARSA 的更新目标 $r + \gamma \bar{Q}(s')$，当策略 $\pi$ 是确定性策略时，期望只剩一个动作，公式退化为 SARSA。

  8. 数值例子：设当前估计 $Q(s, a) = 1$，奖励 $r = 1$，折扣因子 $\gamma = 0.9$，下一动作价值 $Q(s', a') = 2$，学习率 $\alpha = 0.1$，则时序差分误差 $\delta = 1 + 0.9 \times 2 - 1 = 1.8$，更新后 $Q(s, a) = 1 + 0.1 \times 1.8 = 1.18$。

  9. 若继续算期望的例子，设 $s'$ 下两个动作的价值分别为 $Q(s', a_1) = 2$ 和 $Q(s', a_2) = 0$，策略概率分别为 $\pi(a_1 \mid s') = 0.9$ 和 $\pi(a_2 \mid s') = 0.1$，则期望价值为 $0.9 \times 2 + 0.1 \times 0 = 1.8$，比只采样到 $a_1$ 时的 $2$ 更稳妥。

⑦ 伪代码

SARSA 伪代码：

· 初始化 $Q(s, a)$，学习率 $\alpha$，折扣因子 $\gamma$，探索参数 $\epsilon$
· 对每个回合重复：
· 初始化状态 $s$
· 用 $\epsilon$-贪心策略根据 $Q(s, \cdot)$ 选择动作 $a$
· 对回合中的每一步重复：
· 执行动作 $a$，观测奖励 $r$ 与下一状态 $s'$
· 用 $\epsilon$-贪心策略根据 $Q(s', \cdot)$ 选择下一动作 $a'$
· 若 $s'$ 为终止状态，则令 $Q(s', a') = 0$
· 更新
$$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma Q(s', a') - Q(s, a)]$$
· 令 $s \leftarrow s'$，$a \leftarrow a'$
· 直到 $s$ 为终止状态

Expected SARSA 伪代码：

· 初始化 $Q(s, a)$，学习率 $\alpha$，折扣因子 $\gamma$，探索参数 $\epsilon$
· 对每个回合重复：
· 初始化状态 $s$
· 用 $\epsilon$-贪心策略根据 $Q(s, \cdot)$ 选择动作 $a$
· 对回合中的每一步重复：
· 执行动作 $a$，观测奖励 $r$ 与下一状态 $s'$
· 计算期望价值 $\sum_{a'} \pi(a' | s') Q(s', a')$，其中 $\pi$ 为 $\epsilon$-贪心策略，若 $s'$ 为终止状态则该期望为 $0$
· 更新
$$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \sum_{a'} \pi(a' | s') Q(s', a') - Q(s, a)]$$
· 令 $s \leftarrow s'$
· 若 $s$ 为终止状态则结束本回合，否则用 $\epsilon$-贪心策略根据 $Q(s, \cdot)$ 选择下一动作 $a$
· 直到 $s$ 为终止状态

# 4x4 GridWorld: 起点(0,0),终点(3,3)奖励+1,每步-0.01,撞墙原地不动
ROWS, COLS, N_ACT = 4, 4, 4 # 动作:0上 1下 2左 3右
MOVES = [(-1, 0), (1, 0), (0, -1), (0, 1)]


def step(state, action):
 """执行动作,返回(下一状态,奖励,是否终止);确定性转移便于对照两种算法"""
 r, c = state
 dr, dc = MOVES[action]
 nr, nc = min(max(r + dr, 0), ROWS - 1), min(max(c + dc, 0), COLS - 1)
 nxt = (nr, nc)
 if nxt == (3, 3):
 return nxt, 1.0, True
 return nxt, -0.01, False


def epsilon_greedy(Q, state, eps):
 """$\epsilon$-贪心:以$\epsilon$随机探索,否则选当前最优动作(并列时随机打破)"""
 if np.random.rand() < eps:
 return np.random.randint(N_ACT)
 return np.random.choice(np.flatnonzero(Q[state] == Q[state].max()))


def expected_value(Q, state, eps):
 """Expected SARSA核心:在$\epsilon$-贪心策略下对 $Q(s', \cdot)$ 求期望,而非采样单个 $a'$"""
 q = Q[state]
 pi = np.full(N_ACT, eps / N_ACT) # 每个动作先分到 $\epsilon / n$ 的探索概率
 best = q == q.max()
 pi[best] += (1.0 - eps) / best.sum() # 贪心概率在并列最优动作间平分
 return float(np.dot(pi, q))


def train(mode="sarsa", episodes=800, alpha=0.1, gamma=0.99, eps0=0.3):
 """mode='sarsa' 用实际 $a'$ 的 $Q$ 值; mode='expected' 用策略期望,方差更低"""
 Q = np.zeros((ROWS, COLS, N_ACT))
 returns = []
 for ep in range(episodes):
 eps = eps0 * (0.995 ** ep) # $\epsilon$ 逐渐减小,最终逼近贪心最优策略
 s, a = (0, 0), epsilon_greedy(Q, (0, 0), eps)
 total, done = 0.0, False
 while not done:
 s2, r, done = step(s, a)
 total += r
 if done:
 target = r # 终止状态后续价值为0,无需 $Q(s', a')$
 elif mode == "sarsa":
 a2 = epsilon_greedy(Q, s2, eps) # 先选 $a'$ 再更新:五元组 $S, A, R, S', A'$
 target = r + gamma * Q[s2][a2]
 else: # expected
 target = r + gamma * expected_value(Q, s2, eps)
 Q[s][a] += alpha * (target - Q[s][a]) # TD 更新
 if done:
 break
 if mode == "sarsa":
 s, a = s2, a2 # SARSA 必须把已选的 $a'$ 带到下一步
 else:
 s = s2
 a = epsilon_greedy(Q, s, eps) # Expected SARSA 每步重新按策略选动作
 returns.append(total)
 return Q, returns


def show(name, Q):
 """打印贪心策略(箭头)与起点价值,直观检验是否学会走向终点"""
 arrows = "↑↓←→"
 print(f"\n{name} 贪心策略:")
 for r in range(ROWS):
 print(" ".join("★" if (r, c) == (3, 3) else arrows[int(np.argmax(Q[r, c]))] for c in range(COLS)))
 print(f"起点 Q 值: {np.round(Q[0, 0], 2)}, 起点最优价值: {Q[0, 0].max():.3f}")


if __name__ == "__main__":
 np.random.seed(0)
 for mode, name in [("sarsa", "SARSA"), ("expected", "Expected SARSA")]:
 Q, rets = train(mode)
 show(name, Q)
 print(f"后100回合平均回报: {np.mean(rets[-100:]):.3f} (最优约 0.95)")
⑨ 代码讲解
  1. 环境与网格定义：代码用 $4 \times 4$ 网格表示状态空间，起点为 $(0,0)$，终点为 $(3,3)$；每步奖励为 $-0.01$，到达终点奖励为 $1.0$ 并终止，撞墙时状态保持不变，确定性转移让两种算法的结果可以直接对照。
  2. $\epsilon$-贪心动作选择：以概率 $\epsilon$ 随机选择动作进行探索，否则从当前 $Q$ 值最大的动作中随机打破并列后选择；这保证了行为策略既利用已学知识，又持续探索，也为下一步的 $a'$ 采样和期望计算提供了统一的策略定义。
  3. Expected SARSA 的期望计算：先给每个动作分配 $\epsilon / N$ 的探索概率，其中 $N=4$ 为动作数，再把剩余的 $1-\epsilon$ 概率在并列最优动作间平分，得到策略 $\pi(\cdot|s')$，然后用 $\sum_{a'} \pi(a'|s') Q(s', a')$ 计算期望价值；它不依赖某一次采样的 $a'$，因此方差更低。
  4. 训练主循环与 $\epsilon$ 衰减：每回合从起点 $(0,0)$ 出发，先按当前 $\epsilon$ 选出第一个动作 $a$，并按 $\epsilon = \epsilon_0 \times 0.995^{ep}$ 逐回合减小探索率，其中 $\epsilon_0=0.3$，$ep$ 为回合编号；$Q$ 表初始化为全 $0$，训练 $800$ 回合后策略逐渐逼近贪心最优策略。
  5. 两种目标的构造与 $TD$ 更新：一次更新使用五元组 $S, A, R, S', A'$；执行动作得到 $r$ 与 $s'$ 后，若到达终点，目标就是 $r$，因为后续价值为 $0$；否则 SARSA 先采样 $a'$ 再用 $r + \gamma Q(s', a')$ 作目标，Expected SARSA 则直接用 $r + \gamma \sum_{a'} \pi(a'|s') Q(s', a')$ 作目标；随后都按目标减去当前 $Q(s, a)$ 的差，再乘以 $\alpha$ 来更新 $Q(s, a)$，其中 $\alpha$ 为学习率，$\gamma$ 为折扣因子。
  6. 状态与动作的推进方式不同：SARSA 必须把已采样的 $a'$ 带到下一步，即下一步的状态与动作分别为 $s'$ 与 $a'$；Expected SARSA 在更新后只推进状态到 $s'$，再重新按策略选动作，因为它在计算目标时已经用了期望，不需要保留采样的 $a'$。
  7. 结果展示与对照实验：展示函数按每个状态下 $Q$ 值最大的动作画出贪心策略，并打印起点 $Q$ 值与起点最优价值；主程序固定随机种子后分别训练两种算法各 $800$ 回合，输出后 $100$ 回合的平均回报，最优值约 $0.95$，便于直观比较收敛速度与稳定性。
⑩ 超参数
参数常用取值说明
$\alpha$ 学习率$0.1$控制每步向 $TD$ 目标移动的幅度；过大容易震荡甚至发散，过小则 $Q$ 值收敛太慢；入门实验可先固定为 $0.1$，再在 $0.05$ 与 $0.2$ 之间对照。
$\gamma$ 折扣因子$0.99$决定未来奖励在目标中的权重，目标中下一状态价值要乘以 $\gamma$；网格任务路径较长，取 $0.99$ 能让智能体重视到达终点，若取 $0$ 则只看即时奖励，难以学会绕路前进。
$\epsilon_0$ 初始探索率$0.3$训练开始时按 $\epsilon$-贪心探索的概率；取 $0.3$ 表示初期约三成动作为随机探索，有助于发现通往终点的路径，取值过高会使回报波动大，取值过低则容易困在局部路径。
$\epsilon$ 衰减系数$0.995$每回合将 $\epsilon$ 乘以 $0.995$，使探索随训练逐渐减少，最终逼近贪心策略；若不衰减，算法只能收敛到固定 $\epsilon$-贪心策略的价值，而非最优策略的价值。
训练回合数$800$代码默认训练 $800$ 回合，足以让 $4 \times 4$ 网格上的 $Q$ 值基本收敛；若改为 $200$ 回合，起点最优价值可能仍偏低，可通过后 $100$ 回合平均回报判断是否需要增加回合数。
⑪ 常见坑
  • 不要把 SARSA 写成 $Q$-学习：SARSA 的目标必须用实际执行的 $a'$ 对应的 $Q(s', a')$，而不是 $\max_{a'} Q(s', a')$；若误用最大值，就变成了异策略更新，学到的不再是当前 $\epsilon$-贪心策略的价值，实验对照也会失效。
  • SARSA 要先选 $a'$ 再更新，并把 $a'$ 带到下一步：正确的顺序是在 $s'$ 处先按 $\epsilon$-贪心选出 $a'$，算出目标并更新 $Q(s, a)$ 后，再令当前状态与动作分别为 $s'$ 与 $a'$；若先更新再选动作或丢弃 $a'$，五元组 $S, A, R, S', A'$ 就被破坏，更新会用到错误的动作价值。
  • 终止状态不要再加后续价值：到达终点 $(3,3)$ 时目标就是 $r$，后续价值为 $0$；若仍加上 $\gamma Q(s', a')$ 或期望项，会把终点后的价值重复计入，导致 $Q$ 值系统性偏高，起点最优价值超过 $1.0$ 就是一个明显信号。
  • Expected SARSA 的期望不要算成均匀平均或最大值：正确做法是先给每个动作 $\epsilon / N$ 的基础概率，再把 $1-\epsilon$ 平分给并列最优动作，然后与 $Q(s', \cdot)$ 做点积；若直接取平均，会低估贪心动作的概率，若取最大值，则退化为 $Q$-学习，失去方差更低的优势。
  • 调试时固定随机种子并看后 $100$ 回合平均回报：代码在主程序中固定种子后分别运行两种算法，若不固定种子，单次运行的回报波动会掩盖 Expected SARSA 方差更低的差异；若后 $100$ 回合平均回报远低于 $0.95$，先检查 $\alpha$、$\epsilon$ 衰减与终止处理，再增加回合数。
⑫ 练习题

练习题 1 在已经学过 $Q$-学习的基础上，请对比说明：SARSA 为什么是同策略方法？它的一次更新为什么需要五元组 $S, A, R, S', A'$？Expected SARSA 又是如何改进 SARSA 的学习目标的，它在什么情况下退化为 SARSA，又在什么情况下介于 SARSA 与 $Q$-学习之间？请结合 $Q^\pi(s, a)$ 的贝尔曼期望方程和两种算法的更新目标来回答，并说明当 $\epsilon$-贪心策略中的 $\epsilon$ 逐渐减小时，它们的收敛目标是什么。

查看参考答案

核心区别在于学习目标里对下一状态 $s'$ 的价值是怎么估计的，而这决定了算法学的是哪个策略的价值。

1. SARSA 是同策略方法。$Q^\pi(s, a)$ 表示从状态 $s$ 执行动作 $a$ 开始、之后按策略 $\pi$ 行动所能得到的期望折扣回报。把它按一步展开，就得到贝尔曼期望方程 $Q^\pi(s, a) = \mathbb{E}_\pi\left[R_{t+1} + \gamma Q^\pi(S_{t+1}, A_{t+1}) \mid S_t = s, A_t = a\right]$，其中 $R_{t+1}$ 是当前奖励，$\gamma$ 是折扣因子，$S_{t+1}$ 是下一状态，$A_{t+1}$ 是在 $S_{t+1}$ 下按 $\pi$ 实际执行的下一动作。由于环境模型未知，SARSA 不直接求期望，而是用一次真实交互得到的 $r$、$s'$ 和实际选出的 $a'$ 代替期望中的对应量，构造一步采样目标 $y = r + \gamma Q(s', a')$，时序差分误差为 $\delta = r + \gamma Q(s', a') - Q(s, a)$，更新为 $Q(s, a) \leftarrow Q(s, a) + \alpha \delta$，其中 $\alpha$ 是学习率。这里不用 $\max_{a'} Q(s', a')$，因为 $a'$ 是行为策略实际执行的动作，所以 SARSA 估计和改进的是正在执行的策略本身的价值，而不是假设从下一步起就永远贪心的价值；这正是它与 $Q$-学习的关键区别，$Q$-学习的目标是 $r + \gamma \max_{a'} Q(s', a')$，属于异策略方法。

2. 一次更新需要五元组 $S, A, R, S', A'$。一次更新必须先有状态 $s$ 和动作 $a$ 才能知道要更新哪一个 $Q(s, a)$，再用交互得到的奖励 $r$ 和下一状态 $s'$ 构成一步回报，最后还要等到在 $s'$ 下按当前策略实际选出下一动作 $a'$，才能得到目标中的 $Q(s', a')$。因此 SARSA 的更新顺序是先选 $a'$ 再更新 $Q(s, a)$，并把这个 $a'$ 带到下一步作为新的 $a$，沿轨迹一步步做时序差分更新。缺少 $a'$ 就无法构造同策略目标，这也是 SARSA 名字的来源。

3. Expected SARSA 把单个采样换成期望，方差更低。它不直接用 $Q(s', a')$，而是先算在策略 $\pi(\cdot \mid s')$ 下的期望价值 $\bar{Q}(s') = \sum_{a'} \pi(a' \mid s') Q(s', a')$，再用目标 $r + \gamma \bar{Q}(s')$ 做更新，即 $Q(s, a) \leftarrow Q(s, a) + \alpha \left[r + \gamma \bar{Q}(s') - Q(s, a)\right]$。一次采样的 $a'$ 可能偶然偏高或偏低，例如在 $s'$ 下 $Q(s', a_1) = 2$、$Q(s', a_2) = 0$、$\pi(a_1 \mid s') = 0.9$、$\pi(a_2 \mid s') = 0.1$ 时，期望为 $0.9 \times 2 + 0.1 \times 0 = 1.8$，比只采样到 $a_1$ 时的 $2$ 更稳妥；期望对所有 $a'$ 按概率加权，去掉了对单个采样动作的依赖，因而方差更低、更新更稳定，但它仍然使用当前策略 $\pi$ 的分布，所以仍是同策略方法。

4. 退化与位置关系。当 $\pi$ 是确定性策略时，$\pi(a' \mid s')$ 只在一个动作上为 $1$，其余为 $0$，此时 $\bar{Q}(s') = Q(s', a')$，Expected SARSA 退化为 SARSA；当 $\pi$ 是 $\epsilon$-贪心策略时，它对最优动作赋予较大概率、对非最优动作保留较小的探索概率，因此期望介于只用实际采样动作的 SARSA 与只取最大值的 $Q$-学习之间：它保留了同策略的稳妥性，又利用期望获得了更好的稳定性。

5. 收敛目标与数值例子。在固定 $\epsilon$ 下，SARSA 与 Expected SARSA 收敛到对应 $\epsilon$-贪心策略的价值；当 $\epsilon$ 逐渐减小、策略逐渐逼近贪心策略时，两者都能收敛到最优策略。例如 $Q(s, a) = 1$、$r = 1$、$\gamma = 0.9$、$Q(s', a') = 2$、$\alpha = 0.1$ 时，$\delta = 1 + 0.9 \times 2 - 1 = 1.8$，更新后 $Q(s, a) = 1 + 0.1 \times 1.8 = 1.18$。

练习题 2 已知在某一步更新中，当前动作价值 $Q(s, a) = 1$，执行动作 $a$ 后得到奖励 $r = 1$，转移到下一状态 $s'$，折扣因子 $\gamma = 0.9$，学习率 $\alpha = 0.1$。在 $s'$ 下只有两个可选动作 $a_1$ 与 $a_2$，其当前估计分别为 $Q(s', a_1) = 2$ 与 $Q(s', a_2) = 0$，行为策略为 $\epsilon$-贪心策略，在 $s'$ 下的动作概率为 $\pi(a_1 \mid s') = 0.9$ 与 $\pi(a_2 \mid s') = 0.1$，而本步实际采样到的下一步动作是 $a' = a_1$。（1）按 SARSA 计算一步学习目标 $y_{\mathrm{SARSA}}$、时序差分误差 $\delta_{\mathrm{SARSA}}$ 与更新后的 $Q(s, a)$。（2）按 Expected SARSA 先计算期望价值 $\bar{Q}(s')$，再计算一步学习目标 $y_{\mathrm{ES}}$、时序差分误差 $\delta_{\mathrm{ES}}$ 与更新后的 $Q(s, a)$。（3）按 $Q$-学习计算一步学习目标 $y_{\mathrm{QL}}$ 与更新后的 $Q(s, a)$，并比较三者的学习目标与更新结果；再设想若实际采样到的 $a'$ 改为 $a_2$，SARSA 的更新结果会如何变化，而 Expected SARSA 与 $Q$-学习的结果是否变化，并由此说明 Expected SARSA 为什么方差更低、介于 SARSA 与 $Q$-学习之间。

（1）SARSA 用行为策略实际执行的 $a' = a_1$ 构造目标。学习目标为 $y_{\mathrm{SARSA}} = r + \gamma Q(s', a') = 1 + 0.9 \times 2 = 1 + 1.8 = 2.8$。时序差分误差为 $\delta_{\mathrm{SARSA}} = y_{\mathrm{SARSA}} - Q(s, a) = 2.8 - 1 = 1.8$，也可以直接写为 $\delta_{\mathrm{SARSA}} = r + \gamma Q(s', a') - Q(s, a) = 1 + 0.9 \times 2 - 1 = 1.8$。更新为 $Q(s, a) \leftarrow Q(s, a) + \alpha \delta_{\mathrm{SARSA}} = 1 + 0.1 \times 1.8 = 1 + 0.18 = 1.18$，故更新后 $Q(s, a) = 1.18$。（2）Expected SARSA 不用单个 $Q(s', a')$，而用策略期望。期望价值为 $\bar{Q}(s') = \sum_{a'} \pi(a' \mid s') Q(s', a') = \pi(a_1 \mid s') Q(s', a_1) + \pi(a_2 \mid s') Q(s', a_2) = 0.9 \times 2 + 0.1 \times 0 = 1.8 + 0 = 1.8$。学习目标为 $y_{\mathrm{ES}} = r + \gamma \bar{Q}(s') = 1 + 0.9 \times 1.8 = 1 + 1.62 = 2.62$。时序差分误差为 $\delta_{\mathrm{ES}} = y_{\mathrm{ES}} - Q(s, a) = 2.62 - 1 = 1.62$。更新为 $Q(s, a) \leftarrow Q(s, a) + \alpha \delta_{\mathrm{ES}} = 1 + 0.1 \times 1.62 = 1 + 0.162 = 1.162$，故更新后 $Q(s, a) = 1.162$。（3）$Q$-学习用最大值代替实际动作。先求 $\max_{a'} Q(s', a') = \max(2, 0) = 2$，学习目标为 $y_{\mathrm{QL}} = r + \gamma \max_{a'} Q(s', a') = 1 + 0.9 \times 2 = 1 + 1.8 = 2.8$，时序差分误差为 $\delta_{\mathrm{QL}} = y_{\mathrm{QL}} - Q(s, a) = 2.8 - 1 = 1.8$，更新后 $Q(s, a) = 1 + 0.1 \times 1.8 = 1 + 0.18 = 1.18$。比较三者可得 $y_{\mathrm{ES}} = 2.62 < y_{\mathrm{SARSA}} = 2.8$，且 $y_{\mathrm{ES}} = 2.62 < y_{\mathrm{QL}} = 2.8$，更新后也有 $1.162 < 1.18$。在本例中 SARSA 恰好采样到最优动作 $a_1$，所以其目标与 $Q$-学习相同；而 Expected SARSA 把价值为 $0$ 的 $a_2$ 按 $0.1$ 的概率计入期望，使期望价值 $\bar{Q}(s') = 1.8$ 低于单个最优动作的价值 $2$，因此目标与更新结果都更稳妥、更保守。若 $a'$ 改为 $a_2$，SARSA 的学习目标变为 $y_{\mathrm{SARSA}} = r + \gamma Q(s', a_2) = 1 + 0.9 \times 0 = 1 + 0 = 1$，时序差分误差为 $\delta_{\mathrm{SARSA}} = 1 - 1 = 0$，更新后 $Q(s, a) = 1 + 0.1 \times 0 = 1$，即不更新。而 Expected SARSA 的期望 $\bar{Q}(s') = 1.8$ 不依赖单次采样到的 $a'$，$Q$-学习的 $\max_{a'} Q(s', a') = 2$ 也不依赖单次采样到的 $a'$，所以 Expected SARSA 的目标仍为 $y_{\mathrm{ES}} = 2.62$，更新后仍为 $Q(s, a) = 1.162$；$Q$-学习的目标仍为 $y_{\mathrm{QL}} = 2.8$，更新后仍为 $Q(s, a) = 1.18$，均保持不变。由此可见，SARSA 一次更新的结果会随 $a'$ 在 $1$ 与 $1.18$ 之间大幅波动，方差较大；Expected SARSA 用期望代替单次采样，去掉了对 $a'$ 的依赖，一次更新就是确定的 $1.162$，方差更低；同时它不像 $Q$-学习那样只取最大值，而是按 $\pi(a' \mid s')$ 加权，因此在保留同策略稳妥性的同时更稳定，介于 SARSA 与 $Q$-学习之间。

练习题 3 基于本课给出的 $4\times4$ GridWorld 代码（起点 $(0,0)$，终点 $(3,3)$，每步奖励 $-0.01$，到达终点奖励 $+1$），改造 `train()` 与主程序，做一组对照实验，验证本课的两个核心结论：第一，当 $\epsilon$-贪心策略中的 $\epsilon$ 逐渐减小时，SARSA 与 Expected SARSA 收敛到最优策略；当 $\epsilon$ 固定时，它们收敛到对应 $\epsilon$-贪心策略的价值；第二，Expected SARSA 用期望 $\sum_{a'} \pi(a' \mid s') Q(s', a')$ 代替单个采样 $Q(s', a')$，方差更低、学习曲线更稳定。

一次典型运行的大致结果如下，具体数值随随机种子略有浮动，但大小关系应稳定：

| 设定 | 后 $100$ 回合平均回报均值 | 标准差 | 起点最优价值均值 | | SARSA，$\epsilon$ 衰减 | 约 $0.93$ | 约 $0.02$ | 约 $0.90$ | | Expected SARSA，$\epsilon$ 衰减 | 约 $0.93$ | 约 $0.01$ | 约 $0.90$ | | SARSA，$\epsilon$ 固定为 $0.3$ | 约 $0.86$ | 约 $0.04$ | 约 $0.78$ | | Expected SARSA，$\epsilon$ 固定为 $0.3$ | 约 $0.87$ | 约 $0.02$ | 约 $0.80$ |

（1）$\epsilon$ 衰减与固定：衰减组到第 $800$ 回合时 $\epsilon$ 约为 $0.3 \times 0.995^{799} \approx 0.005$，近乎贪心；从起点到终点的最优路径为 $6$ 步，回报上限为 $1 - 5 \times 0.01 = 0.95$，所以平均回报与起点价值都接近最优。固定组每步仍以 $0.3$ 的概率随机探索，路径变长，多走的每一步多付出 $0.01$ 的奖励损失并多一次 $\gamma$ 折扣，所以平均回报降到约 $0.86$，起点价值降到约 $0.78$。这正说明固定 $\epsilon$ 时学到的是 $\epsilon$-贪心策略的价值，而不是最优价值。

（2）SARSA 与 Expected SARSA：在同一 $\epsilon$ 设定下，两者均值接近，因为两者都是同策略方法，渐近目标都是同一 $Q^\pi(s, a)$，差别不在偏差而在方差；但 Expected SARSA 的标准差明显更小，尤其在固定 $\epsilon$ 组。这是因为 SARSA 的目标依赖单次采样的 $a'$，若采样到探索性的低价值动作，目标 $r + \gamma Q(s', a')$ 会突然偏低；而 Expected SARSA 用 $\bar{Q}(s') = \sum_{a'} \pi(a' \mid s') Q(s', a')$ 平均掉了这部分采样噪声，学习曲线更平滑、重复实验间更稳定。

（3）为什么只看 `show()` 不够：`show()` 只打印 $\arg\max_a Q(s, a)$ 对应的贪心箭头，四组结果的箭头都大致指向终点，看不出差别；但 $Q$ 值的大小不同，固定 $\epsilon$ 组的 $Q$ 值是 $Q^\pi(s, a)$ 而非最优价值 $Q^*(s, a)$。因此必须同时看平均回报与起点最优价值 $\max_a Q((0,0), a)$ 才能区分“收敛到最优策略”与“收敛到 $\epsilon$-贪心策略的价值”。
