第 9 课 · Dueling DQN

Dueling DQN · RL 算法每日精讲 · 2026-11-23 · 深度值函数 · 进阶 · 约 35 分钟

前置知识：DQN、Double DQN

把动作价值拆成状态好坏与动作优劣，分别学习再合并。

讲解视频 · Dueling DQN · 8 分 28 秒

① 问题设定

本课考虑离散动作的马尔可夫决策过程，智能体在每个时刻观察状态 $s$，选择动作 $a$，环境返回奖励 $r$ 并转移到下一状态 $s'$，目标是学习使长期折扣回报最大的策略。DQN 直接用一个神经网络估计每个状态动作对的动作价值 $Q(s, a)$，但在许多状态下，不同动作的价值差异很小，真正重要的是状态本身的好坏；例如在游戏画面中，大多数动作都不会立即改变局面，网络却要为每个动作单独学习相近的数值，样本效率较低。Dueling DQN 要解决的正是如何在不改变动作价值定义和训练目标的前提下，让网络更高效地学习状态价值，并把动作之间的相对优势分离出来，其核心分解为 $Q(s, a) = V(s) + A(s, a)$，其中 $V(s)$ 表示状态 $s$ 的价值，$A(s, a)$ 表示动作 $a$ 的优势。它适用于状态空间高维、动作空间离散、奖励稀疏或动作价值差异较小的任务，例如 Atari 游戏、机器人离散控制和离散推荐选择。输入是当前状态 $s$，通常为图像或特征向量；输出是该状态下每个候选动作 $a$ 的估计动作价值 $Q(s, a)$，智能体据此选择价值最大的动作，训练时仍使用经验回放和目标网络，并以折扣因子 $\gamma$ 衡量未来奖励的重要性。

② 核心思想
  • 将动作价值分解为状态价值与优势函数之和，即 $Q(s, a) = V(s) + A(s, a)$，其中 $V(s)$ 衡量状态本身的好坏，$A(s, a)$ 衡量动作 $a$ 相对于该状态平均水平的优劣。
  • 优势函数存在不可辨识性：给 $V(s)$ 加上常数 $c$、给 $A(s, a)$ 减去同一常数 $c$，得到的 $Q(s, a)$ 不变，因此需要用约束固定分解方式。
  • 实践中采用均值中心化聚合：$Q(s, a) = V(s) + A(s, a) - \frac{1}{|\mathcal{A}|} \sum_{a' \in \mathcal{A}} A(s, a')$，用所有动作优势的均值作为基准，使优势的均值为 $0$，从而稳定学习并保留动作间的相对排序。
  • 网络结构分为共享特征层、价值流和优势流：共享层提取状态 $s$ 的表示，价值流输出一个标量 $V(s)$，优势流输出每个动作 $a$ 对应的 $A(s, a)$，最后在聚合层合并得到 $Q(s, a)$。
  • 价值流在所有动作的更新中都能得到训练信号，因此即使某个动作 $a$ 很少被选择，网络仍能从其他动作的样本中学习 $V(s)$，从而提高样本效率，尤其在动作价值差异较小的状态下效果更明显。
  • Dueling DQN 只改变网络结构，不改变 $Q$ 学习的损失、经验回放和目标网络机制，因此可以直接与 Double DQN 结合，用在线网络选择动作、用目标网络评估价值，减少过估计。
③ 与已学方法对比

与第7课的 DQN 相比，Dueling DQN 不改变经验回放、目标网络和 $Q$ 学习的目标，只把网络结构改为价值流加优势流的双流结构，因此能在动作价值差异很小的状态下更快学会 $V(s)$，样本效率更高，在 Atari 等任务上收敛更稳定；与第8课的 Double DQN 相比，两者解决的问题互补，Double DQN 用在线网络选动作、目标网络评估来抑制 $Q(s, a)$ 的过估计，Dueling DQN 则通过结构先验缓解价值估计的方差和泛化问题，二者可以叠加使用。代价是网络参数和计算量略有增加，需要处理优势函数的不可辨识性并选择均值或最大值中心化方式；当动作价值差异本身很大、每个动作都需要精细区分时，收益有限，优势流甚至可能引入额外噪声。

④ 学习流程
  1. 观察初始化网络与状态初始化在线网络参数 $\theta$ 与目标网络参数 $\theta^{-}$，令 $\theta^{-}=\theta$，初始化经验回放池 $\mathcal{D}$，设置折扣因子 $\gamma$、探索率 $\epsilon$ 与批量大小 $B$，观察初始状态 $s$。
  2. 决策选择动作以概率 $\epsilon$ 随机选择动作 $a$，否则选择 $a=\arg\max_{a'} Q(s, a'; \theta)$，输入为当前状态 $s$，输出为待执行的动作 $a$。
  3. 行动执行动作在环境中执行动作 $a$，输入为状态 $s$ 与动作 $a$，等待环境转移并返回奖励与下一状态。
  4. 反馈存储转移采样观察奖励 $r$ 与下一状态 $s'$，将 $(s, a, r, s')$ 存入 $\mathcal{D}$，令 $s=s'$，并从 $\mathcal{D}$ 中随机采样批量大小为 $B$ 的转移。
  5. 计算计算价值优势对采样状态 $s$，共享层提取特征，价值流输出 $V(s)$，优势流输出每个动作的 $A(s, a)$，用均值中心化聚合得到 $Q(s, a)=V(s)+A(s, a)-\frac{1}{|\mathcal{A}|}\sum_{a'\in\mathcal{A}}A(s, a')$。
  6. 计算计算目标损失用在线网络选择下一动作 $a^*=\arg\max_{a'} Q(s', a'; \theta)$，用目标网络评估得到目标值 $y=r+\gamma Q(s', a^*; \theta^{-})$，终止状态时 $y=r$，计算损失 $L(\theta)=(y-Q(s, a; \theta))^2$ 并对批量取平均。
  7. 更新更新网络参数对损失 $L(\theta)$ 求梯度并用梯度下降更新在线网络参数 $\theta$，每隔 $C$ 步令 $\theta^{-}=\theta$，使目标网络与在线网络同步。
  8. 循环判断循环继续若训练未结束且回合未结束，令当前状态为 $s'$ 并返回选择动作继续下一轮；若回合结束则重置 $s$ 为初始状态，直至训练结束。
⑤ 关键公式

价值优势分解

$$Q(s, a) = V(s) + A(s, a)$$

该式把 $Q(s, a)$ 拆成两部分：$V(s)$ 只与状态 $s$ 有关，表示该状态本身的好坏；$A(s, a)$ 表示动作 $a$ 相对该状态平均水平的优劣。网络不再直接为每个动作单独学习相近的数值，而是先学好 $V(s)$，再学习动作之间的相对差异。

  • $Q(s, a)$：在状态 $s$ 下执行动作 $a$ 后得到的期望折扣回报
  • $V(s)$：状态 $s$ 的价值，即从 $s$ 出发按当前策略行动的期望折扣回报
  • $A(s, a)$：在状态 $s$ 下动作 $a$ 的优势，即该动作比状态平均水平好多少
  • $s$：智能体当前观察到的状态
  • $a$：智能体在状态 $s$ 下选择的动作

均值中心化聚合

$$Q(s, a) = V(s) + A(s, a) - \frac{1}{|\mathcal{A}|} \sum_{a' \in \mathcal{A}} A(s, a')$$

直接相加存在不可辨识性，因此减去所有动作优势的均值作为基准，使中心化后的优势均值为 $0$。这样 $V(s)$ 被固定为 $Q(s, a)$ 在所有动作上的平均值，分解方式唯一，学习过程更稳定，同时保留了动作间的相对排序。

  • $Q(s, a)$：聚合后得到的动作价值估计
  • $V(s)$：价值流输出的状态价值
  • $A(s, a)$：优势流输出的原始优势
  • $|\mathcal{A}|$：离散动作集合 $\mathcal{A}$ 中的动作总数
  • $\frac{1}{|\mathcal{A}|} \sum_{a' \in \mathcal{A}} A(s, a')$：所有动作优势的均值，用作中心化基准
  • $a'$：求和时遍历的任意一个候选动作

Double DQN 目标值

$$y = r + \gamma Q(s', \arg\max_{a'} Q(s', a'; \theta); \theta^{-})$$

该式把 Dueling DQN 与 Double DQN 结合：用参数为 $\theta$ 的在线网络先选出下一状态 $s'$ 下价值最大的动作，再用参数为 $\theta^{-}$ 的目标网络评估该动作的价值，从而减少直接取最大值带来的过估计。若 $s'$ 为终止状态，则目标值 $y$ 直接等于奖励 $r$。

  • $y$：用于监督 $Q(s, a; \theta)$ 的目标值
  • $r$：执行动作 $a$ 后环境返回的即时奖励
  • $\gamma$：折扣因子，衡量未来奖励相对于即时奖励的重要性，取值在 $0$ 与 $1$ 之间
  • $s'$：执行动作 $a$ 后转移到的下一状态
  • $\theta$：在线网络的参数
  • $\theta^{-}$：目标网络的参数，定期从 $\theta$ 同步得到

Dueling DQN 损失函数

$$L(\theta) = \mathbb{E}_{(s, a, r, s') \sim \mathcal{D}} \left[ (y - Q(s, a; \theta))^2 \right]$$

损失是目标值 $y$ 与当前估计 $Q(s, a; \theta)$ 之差的平方在经验回放池 $\mathcal{D}$ 上的期望，训练时用批量样本的平均值近似该期望。最小化该损失会同时更新价值流与优势流的参数，使 $V(s)$ 与 $A(s, a)$ 协同拟合 $Q(s, a)$。

  • $L(\theta)$：在线网络参数为 $\theta$ 时的训练损失
  • $y$：由目标网络计算得到的监督目标值
  • $Q(s, a; \theta)$：在线网络对状态 $s$ 下动作 $a$ 的动作价值估计
  • $\mathcal{D}$：经验回放池，存放历史转移样本的集合
  • $(s, a, r, s')$：从 $\mathcal{D}$ 中采样的一条转移，包含状态、动作、奖励与下一状态
⑥ 数学推导

  1. 第一步，从定义出发：$Q^\pi(s, a)$ 是从状态 $s$ 出发先执行动作 $a$、之后按策略 $\pi$ 行动得到的期望折扣回报，$V^\pi(s)$ 是从状态 $s$ 出发直接按策略 $\pi$ 行动得到的期望折扣回报。

  2. 第二步，优势函数定义为动作价值与状态价值之差，它衡量动作 $a$ 比状态 $s$ 的平均水平好多少：

    $$A^\pi(s, a)=Q^\pi(s, a)-V^\pi(s)$$

  3. 第三步，把上式移项，就得到 Dueling DQN 的基本分解：

    $$Q^\pi(s, a)=V^\pi(s)+A^\pi(s, a)$$

  4. 第四步，注意分解并不唯一：给 $V^\pi(s)$ 加上常数 $c$，同时给所有动作的 $A^\pi(s, a)$ 都减去同一个 $c$，得到的 $Q^\pi(s, a)$ 保持不变，因此仅凭 $Q^\pi(s, a)$ 的监督信号无法唯一确定 $V^\pi(s)$ 与 $A^\pi(s, a)$，这就是不可辨识性。

  5. 第五步，用均值中心化固定分解：要求中心化后的优势在所有动作上的均值为 $0$，此时 $V(s)$ 等于 $Q(s, a)$ 在所有动作上的平均值，分解方式被唯一确定：

    $$Q(s, a)=V(s)+A(s, a)-\frac{1}{|\mathcal{A}|}\sum_{a'\in\mathcal{A}}A(s, a')$$

  6. 第六步，这样做还有学习上的好处：价值流的输出 $V(s)$ 会从每个动作的样本中都获得梯度信号，即使某个动作 $a$ 很少被选择，$V(s)$ 仍能通过其他动作的样本得到训练，因此在动作价值差异较小的状态下样本效率更高。

  7. 第七步，看一个小数值例子：设某状态 $s$ 有 $3$ 个动作，价值流输出 $V(s)=10$，优势流原始输出为 $A(s, a_1)=3$、$A(s, a_2)=1$、$A(s, a_3)=-1$，三者均值为 $1$。

  8. 第八步，减去均值 $1$ 后，中心化优势为 $2$、$0$、$-2$，聚合得到 $Q(s, a_1)=12$、$Q(s, a_2)=10$、$Q(s, a_3)=8$，其平均值 $(12+10+8)/3=10$ 恰好等于 $V(s)$，动作排序仍由优势决定。

  9. 第九步，对比无约束情形：若把 $V(s)$ 改为 $11$，同时把原始优势都减 $1$ 变为 $2$、$0$、$-2$，则无约束的 $V(s)+A(s, a)$ 仍为 $13$、$11$、$9$，与原来相同，说明不加约束时 $V(s)$ 与 $A(s, a)$ 无法被唯一确定。

  10. 第十步，训练时仍用 Double DQN 的目标值 $y$ 与损失 $L(\theta)$ 更新参数 $\theta$，Dueling 结构只改变 $Q(s, a)$ 的计算方式，不改变 $Q$ 学习的目标与经验回放机制。

74import random
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
import gymnasium as gym
from collections import deque

# Dueling 网络：共享层 + 价值流 $V(s)$ + 优势流 $A(s,a)$，均值中心化聚合消除不可辨识性
class DuelingQNet(nn.Module):
    def __init__(self, state_dim, action_dim):
        super().__init__()
        self.shared = nn.Sequential(nn.Linear(state_dim, 128), nn.ReLU())  # 共享特征提取
        self.value = nn.Sequential(nn.Linear(128, 128), nn.ReLU(), nn.Linear(128, 1))  # 价值流：输出标量 $V(s)$
        self.advantage = nn.Sequential(nn.Linear(128, 128), nn.ReLU(), nn.Linear(128, action_dim))  # 优势流：每个动作的 $A(s,a)$

    def forward(self, x):
        h = self.shared(x)
        v = self.value(h)
        a = self.advantage(h)
        # 均值中心化：$A$ 减去均值，使优势均值为 $0$，固定分解，保留动作相对排序
        return v + a - a.mean(dim=1, keepdim=True)  # $Q(s,a)=V(s)+A(s,a)-mean(A)$

def main():
    env = gym.make("CartPole-v1")
    state_dim, action_dim = env.observation_space.shape[0], env.action_space.n
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    online = DuelingQNet(state_dim, action_dim).to(device)  # 在线网络 $theta$
    target = DuelingQNet(state_dim, action_dim).to(device)  # 目标网络 $theta^{-}$
    target.load_state_dict(online.state_dict())  # $theta^{-}=theta$
    opt = optim.Adam(online.parameters(), lr=1e-3)
    buffer = deque(maxlen=10000)  # 经验回放池 $D$
    gamma, eps, eps_min, eps_decay = 0.99, 1.0, 0.05, 0.995
    batch, target_update, episodes = 64, 100, 300
    steps = 0
    for ep in range(episodes):
        s, _ = env.reset(seed=ep)
        done, total_reward = False, 0
        while not done:
            # $epsilon$-贪心：探索或利用 $Q$ 最大的动作
            if random.random() < eps:
                a = env.action_space.sample()
            else:
                with torch.no_grad():
                    a = online(torch.tensor(s, dtype=torch.float32, device=device)).argmax().item()
            s2, r, terminated, truncated, _ = env.step(a)
            done = terminated or truncated
            buffer.append((s, a, r, s2, done))
            s, total_reward, steps = s2, total_reward + r, steps + 1
            if len(buffer) >= batch:
                batch_data = random.sample(buffer, batch)
                ss, aa, rr, ss2, dd = zip(*batch_data)
                ss = torch.tensor(np.array(ss), dtype=torch.float32, device=device)
                aa = torch.tensor(aa, dtype=torch.long, device=device)
                rr = torch.tensor(rr, dtype=torch.float32, device=device)
                ss2 = torch.tensor(np.array(ss2), dtype=torch.float32, device=device)
                dd = torch.tensor(dd, dtype=torch.float32, device=device)
                q = online(ss).gather(1, aa.unsqueeze(1)).squeeze(1)  # $Q(s,a;theta)$
                with torch.no_grad():
                    # Double DQN：在线网选动作 $a^*$，目标网评估，避免过估计
                    a_star = online(ss2).argmax(dim=1, keepdim=True)
                    q_next = target(ss2).gather(1, a_star).squeeze(1)
                    y = rr + gamma * q_next * (1 - dd)  # 终止时 $y=r$
                loss = nn.MSELoss()(q, y)  # $L(theta)=(y-Q)^2$ 的批量平均
                opt.zero_grad(); loss.backward(); opt.step()
                if steps % target_update == 0:
                    target.load_state_dict(online.state_dict())  # 每 $C$ 步同步 $theta^{-}=theta$
        eps = max(eps_min, eps * eps_decay)
        if (ep + 1) % 50 == 0:
            print(f"Episode {ep+1}, reward={total_reward:.0f}, eps={eps:.2f}")
    env.close()

if __name__ == "__main__":
    main()
⑨ 代码讲解
  1. 定义 `DuelingQNet`：共享层 `self.shared` 先把状态 $s$ 编码为 $128$ 维特征 $h$；价值流 `self.value` 输出一个标量 $V(s)$，优势流 `self.advantage` 输出每个动作 $a$ 对应的 $A(s, a)$。两条流共用 $h$，因此 $V(s)$ 的学习可以借助所有动作的样本，而不只依赖某个 $a$ 被选中的样本。
  2. 在 `forward` 中用均值中心化聚合：先由 $h$ 得到 $V(s)$ 与 $A(s, a)$，再返回 $Q(s, a)=V(s)+A(s, a)-\frac{1}{|\mathcal{A}|}\sum_{a' \in \mathcal{A}} A(s, a')$。减去均值后优势的均值为 $0$，消除了 $V(s)$ 加 $c$、$A(s, a)$ 减 $c$ 仍得到同一 $Q(s, a)$ 的不可辨识性，同时保留动作间的相对排序，因此 $\arg\max_{a} Q(s, a)$ 不变。
  3. 在 `main` 中创建 CartPole 环境，初始化在线网络 $Q(s, a; \theta)$ 与目标网络 $Q(s, a; \theta^{-})$ 并令 $\theta^{-}=\theta$，用 Adam 优化 $\theta$，学习率为 $10^{-3}$；同时创建容量为 $10000$ 的经验回放池 $D$，并设定折扣因子 $\gamma=0.99$、初始探索率 $\epsilon=1.0$、最小探索率 $\epsilon_{\min}=0.05$、衰减系数 $0.995$、批量大小 $64$、目标网络同步间隔 $100$ 步、总回合数 $300$。
  4. 主循环按 $\epsilon$-贪心与环境交互：以概率 $\epsilon$ 随机采样动作 $a$ 探索，以概率 $1-\epsilon$ 选择 $Q(s, a; \theta)$ 最大的动作 $a$；执行后得到下一状态 $s'$、奖励 $r$ 与终止标志，并把 $(s, a, r, s', done)$ 存入 $D$，同时累计奖励并更新全局步数。注意终止时 $done$ 为真，否则继续执行。
  5. 当 $D$ 中样本数不少于批量大小 $64$ 时，从 $D$ 中随机抽取一个小批量 $(s, a, r, s', done)$，用在线网络得到当前 $Q(s, a; \theta)$；再用 Double DQN 计算目标值：在线网络选出 $a^*=\arg\max_{a'} Q(s', a'; \theta)$，目标网络评估得到 $Q(s', a^*; \theta^{-})$，目标值为 $y=r+\gamma Q(s', a^*; \theta^{-})(1-done)$，终止时 $done=1$，故 $y=r$。最后用均方误差 $L(\theta)=(y-Q(s, a; \theta))^2$ 的批量平均作为损失，对 $\theta$ 做一次梯度下降更新。
  6. 每 $100$ 步把 $\theta$ 同步给 $\theta^{-}$，即令 $\theta^{-}=\theta$，使目标值 $y$ 在一段时间内保持稳定；每个回合结束时按 $\epsilon \leftarrow \max(\epsilon_{\min}, \epsilon \times 0.995)$ 衰减探索率，其中 $\epsilon_{\min}=0.05$，并每 $50$ 个回合打印一次总奖励与当前 $\epsilon$，便于观察学习是否收敛。
⑩ 超参数
参数常用取值说明
折扣因子 $\gamma$$0.99$决定未来奖励 $r$ 的权重：$\gamma$ 越接近 $1$，智能体越看重长期回报，但目标值 $y$ 的方差与训练不稳定性也越大；CartPole 这类需要持续平衡的任务常用 $0.99$，过小会使智能体只顾眼前奖励 $r$。
探索率 $\epsilon$ 及其衰减$1.0 \to 0.05$，每回合乘以 $0.995$训练初期 $\epsilon$ 接近 $1$，以随机动作 $a$ 充分探索；随着 $\epsilon$ 衰减，智能体越来越多地利用 $Q(s, a; \theta)$ 最大的动作 $a$。衰减过快会过早陷入局部最优，衰减过慢则后期仍有大量随机动作 $a$，难以收敛。
学习率 $lr$$10^{-3}$Adam 的步长：$lr$ 过大时 $Q(s, a; \theta)$ 更新不稳定、损失 $L(\theta)$ 震荡甚至发散；$lr$ 过小则 $300$ 个回合内学不充分。可先固定 $10^{-3}$，若损失 $L(\theta)$ 长期不降再尝试 $5\times10^{-4}$ 或 $10^{-4}$。
批量大小 $batch$$64$每次从 $D$ 中抽取 $64$ 条样本计算损失 $L(\theta)$ 的平均梯度：批量太小会使梯度噪声大、$Q(s, a; \theta)$ 更新不稳定；批量太大则计算变慢，且单步更新次数相对减少。$64$ 是 CartPole 上常用且性价比高的折中值。
目标网络同步间隔 $C$$100$ 步每 $100$ 步令 $\theta^{-}=\theta$：$C$ 太小，目标值 $y$ 跟随在线网络 $Q(s, a; \theta)$ 变化过快，容易震荡；$C$ 太大，目标网络 $Q(s, a; \theta^{-})$ 过时，学习变慢。结合批量大小 $64$ 与总步数，$100$ 步是常用起点。
⑪ 常见坑
  • 不要写成 $Q(s, a)=V(s)+A(s, a)$ 直接相加而不减均值：此时 $V(s)$ 与 $A(s, a)$ 不可辨识，训练中两者会相互漂移，$V(s)$ 可能学不到状态本身的好坏。调试时检查 `forward` 是否减去优势均值，并打印同一状态 $s$ 下所有动作 $a$ 的 $A(s, a)$ 均值，确认其接近 $0$。
  • 优势均值必须沿动作维求平均：若对批量维求均值，会错误地把不同状态 $s$ 的优势混在一起，导致 $Q(s, a)$ 计算错误。应按每行、即维度 $1$ 求均值并保留该维；调试时打印一个批量的 $Q(s, a)$ 形状，CartPole 下应为 $64 \times 2$，其中 $2$ 是动作数 $|\mathcal{A}|$。
  • 计算目标值 $y$ 时不要用在线网络同时选动作和评估，也不要让梯度流进目标网络：应由在线网络选出 $a^*$，由目标网络评估 $Q(s', a^*; \theta^{-})$，并在计算 $y$ 时关闭梯度；否则会重新引入过估计，且 $\theta^{-}$ 会被错误更新。调试时检查目标值计算是否在无梯度模式下进行，并确认只有 $\theta$ 参与优化器更新。
  • 若训练 $300$ 个回合后总奖励仍长期低于 $100$，先不要调网络结构：先检查 $\epsilon$ 是否已从 $1.0$ 衰减到 $0.05$ 附近、经验回放池 $D$ 是否已存满批量 $64$ 再开始更新、目标网络是否每 $100$ 步同步；再检查奖励 $r$ 与终止标志 $done$ 是否正确传入目标值 $y=r+\gamma Q(s', a^*; \theta^{-})(1-done)$，其中终止时 $done=1$。
⑫ 练习题

练习题 1 请解释 Dueling DQN 为什么要把 $Q(s, a)$ 分解为状态价值 $V(s)$ 与优势函数 $A(s, a)$ 之和，这种分解存在怎样的不可辨识性问题，均值中心化聚合 $Q(s, a)=V(s)+A(s, a)-\frac{1}{|\mathcal{A}|}\sum_{a' \in \mathcal{A}} A(s, a')$ 是如何固定分解方式的？并进一步说明：这种双流结构为什么能提高样本效率，尤其是在动作价值差异较小的状态下效果更明显？它与 Double DQN 是什么关系？

查看参考答案

Dueling DQN 的出发点是区分状态本身好不好与在这个状态下某个动作比平均水平好多少。记 $Q^\pi(s, a)$ 为从状态 $s$ 出发先执行动作 $a$、之后按策略 $\pi$ 行动得到的期望折扣回报，$V^\pi(s)$ 为从状态 $s$ 出发直接按策略 $\pi$ 行动得到的期望折扣回报，则优势函数定义为 $A^\pi(s, a)=Q^\pi(s, a)-V^\pi(s)$，移项即得 $Q^\pi(s, a)=V^\pi(s)+A^\pi(s, a)$。其中 $V(s)$ 只与 $s$ 有关，衡量状态本身的好坏；$A(s, a)$ 衡量动作 $a$ 相对于该状态平均水平的优劣，正值表示好于平均，负值表示差于平均，接近 $0$ 表示动作选择几乎不影响回报。但仅凭 $Q(s, a)$ 的监督信号无法唯一确定这一分解，这就是不可辨识性。对任意常数 $c$，把 $V(s)$ 改为 $V(s)+c$，同时把所有动作的 $A(s, a)$ 都改为 $A(s, a)-c$，则 $Q(s, a)=V(s)+A(s, a)$ 保持不变，也就是说 $V(s)$ 与 $A(s, a)$ 可以沿着这条方向任意漂移而不改变 $Q(s, a)$，网络学到的 $V(s)$ 就失去了状态价值的语义，训练也不稳定，因此必须加一个约束来固定分解方式。实践中采用均值中心化聚合：$Q(s, a)=V(s)+A(s, a)-\frac{1}{|\mathcal{A}|}\sum_{a' \in \mathcal{A}} A(s, a')$。这里减去的是所有动作优势的均值，中心化后的优势在所有动作上的均值为 $0$，于是 $V(s)$ 等于 $Q(s, a)$ 在所有动作上的平均值，即 $V(s)=\frac{1}{|\mathcal{A}|}\sum_{a' \in \mathcal{A}} Q(s, a')$，分解被唯一确定：若再给 $V(s)$ 加 $c$、给 $A(s, a)$ 减 $c$，中心化优势的均值将变为 $-c$，不再满足均值为 $0$ 的约束，除非 $c=0$。同时，由于对所有动作减去的是同一个均值，动作间的相对排序不变，$\arg\max_{a} Q(s, a)=\arg\max_{a} A(s, a)$，贪心动作不受影响。例如，某状态 $s$ 有 $3$ 个动作，价值流输出 $V(s)=10$，优势流原始输出为 $A(s, a_1)=3$、$A(s, a_2)=1$、$A(s, a_3)=-1$，三者均值为 $1$。减去均值后中心化优势为 $2$、$0$、$-2$，聚合得到 $Q(s, a_1)=12$、$Q(s, a_2)=10$、$Q(s, a_3)=8$，其平均值恰好等于 $V(s)$，排序仍由优势决定。若不加约束，把 $V(s)$ 改为 $11$、把原始优势都减 $1$，无约束的 $V(s)+A(s, a)$ 仍为 $13$、$11$、$9$，与原来相同，这正说明不加约束时 $V(s)$ 与 $A(s, a)$ 无法被唯一确定。结构上，网络先由共享层提取状态 $s$ 的表示，再分出两条流：价值流输出一个标量 $V(s)$，优势流输出每个动作的 $A(s, a)$，最后在聚合层按上式合并。由于 $V(s)$ 出现在每个动作的 $Q(s, a)$ 中，价值流会从每个动作的样本中都获得梯度信号，即使某个动作 $a$ 很少被选择，$V(s)$ 仍能通过其他动作的样本得到训练；优势流只需学习动作间的相对差异，而不必重复学习状态本身的好坏。这在动作价值差异较小的状态下尤其有利：此时各动作的 $A(s, a)$ 都接近 $0$，$Q(s, a)$ 主要由 $V(s)$ 决定，网络可以把容量和样本集中用于学好 $V(s)$，而不必为每个动作分别从头学习几乎相同的 $Q$ 值，从而提高样本效率和泛化能力；在动作选择确实重要的状态下，优势流仍能学出较大的 $A(s, a)$ 差异来区分动作。最后，Dueling DQN 只改变 $Q(s, a)$ 的计算方式与网络结构，不改变 $Q$ 学习的损失、经验回放和目标网络机制，因此可以直接与 Double DQN 结合：用在线网络选择动作，用目标网络评估价值，以减少过估计，Dueling 结构只是让 $Q(s, a)$ 的估计本身更准确、更高效。

练习题 2 设某状态 $s$ 有 $3$ 个动作 $a_1$、$a_2$、$a_3$，即 $|\mathcal{A}|=3$。某时刻 Dueling 网络在状态 $s$ 处输出价值流 $V(s)=10$，优势流原始输出为 $A(s,a_1)=3$、$A(s,a_2)=1$、$A(s,a_3)=-1$。（1）计算原始优势的均值，并用均值中心化聚合公式 $Q(s,a)=V(s)+A(s,a)-\frac{1}{|\mathcal{A}|}\sum_{a'\in\mathcal{A}}A(s,a')$ 求 $Q(s,a_1)$、$Q(s,a_2)$、$Q(s,a_3)$，验证这三个 $Q$ 值的平均值等于 $V(s)$，并指出 $s$ 处的贪心动作。（2）取常数 $c=1$，把 $V(s)$ 改为 $11$，同时把三个原始优势都减去 $1$。分别计算改动前后无约束分解 $V(s)+A(s,a)$ 的三个值，说明这为什么体现了不可辨识性；再结合（1）的结果，说明均值中心化约束为什么能固定分解方式。（3）设智能体在 $s$ 处执行动作 $a_2$，得到奖励 $r=1$，转移到下一状态 $s'$，且未终止，折扣因子 $\gamma=0.99$。在 $s'$ 处，在线网络输出 $V_{online}(s')=6$，原始优势为 $A_{online}(s',a_1)=4$、$A_{online}(s',a_2)=1$、$A_{online}(s',a_3)=-2$；目标网络输出 $V_{target}(s')=8$，原始优势为 $A_{target}(s',a_1)=2$、$A_{target}(s',a_2)=5$、$A_{target}(s',a_3)=-1$。按 Double DQN 的做法，先用在线网络在 $s'$ 处选择动作 $a^*$，再用目标网络评估该动作，求目标值 $y=r+\gamma Q_{target}(s',a^*)$、$Q(s,a_2)$ 的时序差分误差 $\delta$ 与单样本损失 $L=(y-Q(s,a_2))^2$。

查看参考答案

（1）原始优势的均值为 $\frac{3+1+(-1)}{3}=\frac{3}{3}=1$。中心化后的优势为 $3-1=2$、$1-1=0$、$-1-1=-2$，其均值为 $0$。代入均值中心化聚合公式，得 $Q(s,a_1)=10+3-1=12$，$Q(s,a_2)=10+1-1=10$，$Q(s,a_3)=10+(-1)-1=8$。这三个 $Q$ 值的平均值为 $\frac{12+10+8}{3}=\frac{30}{3}=10$，恰好等于 $V(s)=10$。因为 $12$ 是最大值，所以 $s$ 处的贪心动作为 $a_1$。（2）改动前无约束分解为 $10+3=13$、$10+1=11$、$10+(-1)=9$。取 $c=1$ 后，$V(s)$ 变为 $11$，原始优势变为 $2$、$0$、$-2$，无约束分解为 $11+2=13$、$11+0=11$、$11+(-2)=9$，与改动前完全相同。因此仅从 $V(s)+A(s,a)$ 的值无法区分 $V(s)=10$、$A(s,a_1)=3$、$A(s,a_2)=1$、$A(s,a_3)=-1$ 与 $V(s)=11$、$A(s,a_1)=2$、$A(s,a_2)=0$、$A(s,a_3)=-2$ 这两组分解，这就是不可辨识性。均值中心化要求中心化后的优势均值为 $0$，此时 $V(s)$ 必须等于 $Q(s,a)$ 在所有动作上的平均值。对（1）得到的 $Q(s,a_1)=12$、$Q(s,a_2)=10$、$Q(s,a_3)=8$，其平均值为 $10$，故只能取 $V(s)=10$，中心化优势只能取 $2$、$0$、$-2$。若强行取 $V(s)=11$，则 $Q(s,a)-V(s)$ 为 $1$、$-1$、$-3$，其均值为 $-1$，不等于 $0$，违反约束；可见均值中心化排除了上述平移自由度，固定了分解方式。（3）先计算在线网络在 $s'$ 处的 $Q$ 值。原始优势均值为 $\frac{4+1+(-2)}{3}=\frac{3}{3}=1$，中心化优势为 $3$、$0$、$-3$，故 $Q_{online}(s',a_1)=6+4-1=9$，$Q_{online}(s',a_2)=6+1-1=6$，$Q_{online}(s',a_3)=6+(-2)-1=3$。最大值为 $9$，故在线网络选择的动作为 $a^*=a_1$。再计算目标网络在 $s'$ 处的 $Q$ 值。原始优势均值为 $\frac{2+5+(-1)}{3}=\frac{6}{3}=2$，中心化优势为 $0$、$3$、$-3$，故 $Q_{target}(s',a_1)=8+2-2=8$，$Q_{target}(s',a_2)=8+5-2=11$，$Q_{target}(s',a_3)=8+(-1)-2=5$。Double DQN 用目标网络评估在线网络选出的 $a_1$，即 $Q_{target}(s',a^*)=Q_{target}(s',a_1)=8$。注意目标网络自身的最大动作是 $a_2$，但 Double DQN 不直接取 $11$，这正是它减少过估计的关键。目标值为 $y=r+\gamma Q_{target}(s',a^*)=1+0.99\times 8=1+7.92=8.92$。由（1）知当前 $Q(s,a_2)=10$，故时序差分误差为 $\delta=y-Q(s,a_2)=8.92-10=-1.08$。单样本损失为 $L=(y-Q(s,a_2))^2=(-1.08)^2=1.1664$。最终结果为：$Q(s,a_1)=12$、$Q(s,a_2)=10$、$Q(s,a_3)=8$，贪心动作为 $a_1$；$y=8.92$，$\delta=-1.08$，$L=1.1664$。

        else:
            raise ValueError('mode must be mean, max or none')

注意：`mean` 直接返回张量，`max` 返回 `(values, indices)` 这样的二元组，必须取 `[0]` 才能得到最大值张量，否则 `v + a - ...` 会报错；两种聚合都要保留 `keepdim=True`，使减去的量形状为 `(batch, 1)`，才能广播到 $Q(s, a)$ 的形状。

二、$V(s)$ 的含义为什么会变

均值中心化时，对 $Q(s, a)=V(s)+A(s, a)-\frac{1}{|\mathcal{A}|}\sum_{a' \in \mathcal{A}} A(s, a')$ 两边对所有 $a$ 求平均，中心化项相互抵消，得到 $V(s)=\frac{1}{|\mathcal{A}|}\sum_{a \in \mathcal{A}} Q(s, a)$，即 $V(s)$ 是 $Q(s, a)$ 在所有动作上的平均值，中心化后的优势均值为 $0$。

最大值中心化时，设 $a^*=\arg\max_{a \in \mathcal{A}} A(s, a)$，则 $Q(s, a^*)=V(s)$，所以 $V(s)=\max_{a \in \mathcal{A}} Q(s, a)$，即 $V(s)$ 是最优动作的 $Q$ 值；中心化后最优动作的优势为 $0$，其余动作的优势小于或等于 $0$。

无约束时 $Q(s, a)=V(s)+A(s, a)$，取任意常数 $c$，令 $V'(s)=V(s)+c$、$A'(s, a)=A(s, a)-c$，仍有 $V'(s)+A'(s, a)=V(s)+A(s, a)$，所以 $V(s)$ 既不是平均值也不是最大值，没有确定的含义。

三、预期看到的现象

1. 表达能力相同，差别在优化：三种聚合都能表示同一组 $Q(s, a)$，因为 $V(s)$ 可以整体平移来吸收常数差，所以最终学到的策略和 $Q(s, a)$ 在理想情况下应接近，差别主要体现在训练稳定性和速度上，而不是能否表示。

2. 奖励曲线：`'mean'` 最稳定、上升最快，滑动平均奖励最先达到高位且波动最小；`'max'` 接近 `'mean'`，但波动稍大、上升稍慢；`'none'` 上升最慢、曲线波动最大，在 $300$ 个回合内可能仍未稳定到与前两者相同的水平。原因是均值聚合让 $V(s)$ 从每个动作的样本都获得梯度，而最大值聚合对最优动作的优势梯度会被抵消，无约束时 $V(s)$ 与 $A(s, a)$ 还会互相漂移。

梯度细节：均值聚合时 $\frac{\partial Q(s, a)}{\partial A(s, a)}=1-\frac{1}{|\mathcal{A}|}$，对其他动作的偏导为 $-\frac{1}{|\mathcal{A}|}$，所有优势都参与更新；最大值聚合时，若 $a$ 就是最优动作，则 $Q(s, a)=V(s)$，其优势的偏导为 $0$，若 $a$ 不是最优动作，则自身偏导为 $1$、最优动作的偏导为 $-1$；无约束时自身偏导为 $1$，但 $V(s)$ 与 $A(s, a)$ 会同时获得同一时序差分误差的梯度，容易同向漂移。

3. 固定状态 $s_0$ 的打印：设示意性的最终 $Q(s_0, a)$ 为 $12$、$10$、$8$，则 `'mean'` 应看到 $V(s_0)=10$、中心化优势为 $2$、$0$、$-2$；`'max'` 应看到 $V(s_0)=12$、中心化优势为 $0$、$-2$、$-4$；`'none'` 的 $Q(s_0, a)$ 仍可接近 $12$、$10$、$8$，但 $V(s_0)$ 可能漂移到例如 $15$，原始优势为 $-3$、$-5$、$-7$，既不等于 $Q$ 的平均值，也不等于最大值。实际数值会随随机种子和初始化变化，不要期望与示意数完全相同，关键是看 $V(s_0)$ 与 $Q(s_0, a)$ 平均值或最大值的关系是否成立。

4. 常见错误：忘记给 `max` 加 `[0]` 会报错；去掉 `keepdim=True` 会导致广播形状错误；只改 `online` 不改 `target`，或三种模式共用同一个 `buffer`，都会使对比失效；改动损失或目标值 $y=r+\gamma Q_{target}(s', a^*)$（其中 $a^*$ 由在线网络选择）就不再是单纯的聚合消融实验。
