第 8 课 · Double DQN

Double DQN · RL 算法每日精讲 · 2026-11-22 · 深度值函数 · 进阶 · 约 30 分钟

前置知识：DQN

用在线网络选动作、目标网络评价值，解耦选择与评估。

讲解视频 · Double DQN · 7 分 19 秒

① 问题设定

在第 7 课的 DQN 中，智能体用深度神经网络近似动作价值函数 $Q(s, a)$，并通过经验回放和目标网络进行离策略学习。然而，DQN 的目标值使用 $\max_{a'} Q(s', a'; \theta^-)$ 对下一状态 $s'$ 的所有动作取最大值，这会系统性地高估真实价值：当 $Q$ 的估计存在噪声时，最大值运算总倾向于挑中被高估的动作，即使其真实价值并不高，这种偏差会沿着自举过程不断累积和放大，导致策略学到次优甚至错误的动作。Double DQN 正是为纠正这一最大化偏差而设计的改进算法。它仍然面向离散动作空间、状态空间高维连续的任务，例如雅达利游戏、机器人控制的离散化动作选择和推荐系统中的离散决策，输入为当前状态 $s$、以及与环境交互得到的奖励 $r$ 和下一状态 $s'$，训练数据来自经验回放池 $D$ 中的转移样本 $(s, a, r, s')$；输出为经过修正的在线网络 $Q(s, a; \theta)$，由此导出贪心策略 $\pi(s) = \arg\max_a Q(s, a; \theta)$。与普通 DQN 相比，它不增加新的网络结构，只改变目标值的计算方式，因此可以在几乎相同的计算代价下获得更准确的价值估计和更稳定的学习效果。

② 核心思想
  • 最大化偏差是问题的根源：DQN 的目标使用 $\max_{a'} Q(s', a'; \theta^-)$ 同时完成动作选择与价值评估，估计噪声会被最大值运算放大，导致 $Q(s, a)$ 系统性高估。
  • 解耦选择与评估是核心解法：用在线网络 $Q(s, a; \theta)$ 选择下一状态 $s'$ 下的最优动作 $a^*$，再用目标网络 $Q(s, a; \theta^-)$ 评估该动作的价值，避免同一个网络既选又评。
  • 目标值公式随之改变：对非终止转移，目标为 $y = r + \gamma Q(s', a^*; \theta^-)$，其中 $a^* = \arg\max_{a'} Q(s', a'; \theta)$；对终止转移，则直接令 $y = r$。
  • 其余训练流程与 DQN 相同：仍使用经验回放、基于 $\epsilon$ 的贪心探索、小批量梯度下降和周期性同步目标网络，因此可以很方便地在已有 DQN 代码上只改一行目标计算。
  • 效果与局限并存：解耦能显著减轻高估、提升策略质量和稳定性，但不能完全消除估计误差，且仍依赖目标网络与经验回放来抑制自举带来的不稳定。
③ 与已学方法对比

与第 7 课的 DQN 相比，Double DQN 解决的是 DQN 固有的最大化偏差问题：DQN 用同一个目标网络既选动作又评价值，容易高估 $Q(s, a)$ 并把误差自举放大；Double DQN 用在线网络 $Q(s, a; \theta)$ 选动作、用目标网络 $Q(s, a; \theta^-)$ 评价值，显著降低高估、提升雅达利等任务上的得分与稳定性。与第 5 课的 Q-Learning 相比，它继承了表格 Q-Learning 的解耦思想并将其推广到深度网络，而与第 6 课的 SARSA 相比，它仍保持离策略学习的高样本效率，不必等待真实下一动作 $a'$。代价很小：不需要增加网络参数或额外超参数，计算量几乎不变；但它并未完全消除估计误差，对噪声很大的任务仍可能高估，且仍依赖经验回放和目标网络来维持稳定。

④ 学习流程
  1. 计算初始化网络随机初始化在线网络 $Q(s, a; \theta)$ 的参数 $\theta$，并令目标网络参数 $\theta^- \leftarrow \theta$；同时初始化经验回放池 $D$，设定折扣因子 $\gamma$、批量大小 $B$ 与目标网络同步间隔 $C$。
  2. 观察观察状态每回合开始时从环境获得初始状态 $s$，并将其作为当前状态输入在线网络 $Q(s, a; \theta)$，为后续选动作做准备。
  3. 决策贪心选动作根据 $Q(s, a; \theta)$ 以基于 $\epsilon$ 的贪心策略选择动作 $a$：以概率 $1 - \epsilon$ 选择价值最高的动作，以概率 $\epsilon$ 随机探索。
  4. 行动执行动作在环境中执行动作 $a$，环境据此转移到下一状态 $s'$ 并给出即时奖励 $r$。
  5. 反馈观测反馈观测奖励 $r$ 与下一状态 $s'$，并将转移 $(s, a, r, s')$ 存入经验回放池 $D$，供后续小批量训练使用。
  6. 计算解耦算目标从 $D$ 中随机采样小批量 $\{(s_j, a_j, r_j, s_j')\}_{j=1}^{B}$；对每个样本 $j$，先用在线网络选出 $a_j^* = \arg\max_{a'} Q(s_j', a'; \theta)$，再用目标网络评估并计算 $y_j = r_j + \gamma Q(s_j', a_j^*; \theta^-)$，若 $s_j'$ 为终止状态则 $y_j = r_j$。
  7. 更新计算损失更新计算小批量均方损失 $L(\theta) = \frac{1}{B} \sum_{j=1}^{B} (y_j - Q(s_j, a_j; \theta))^2$，并对 $L(\theta)$ 关于 $\theta$ 求梯度，用梯度下降更新在线网络参数 $\theta$。
  8. 循环同步与循环每经过 $C$ 步更新，令 $\theta^- \leftarrow \theta$ 同步目标网络；若 $s'$ 为终止状态则结束本回合，否则令 $s \leftarrow s'$ 并进入下一时间步继续循环。
⑤ 关键公式

DQN 目标值（高估来源）

$$y^{\mathrm{DQN}} = r + \gamma \max_{a'} Q(s', a'; \theta^-)$$

这是普通 DQN 的目标值计算方式，同一个目标网络 $Q(s', a'; \theta^-)$ 既负责挑出价值最大的动作，又负责评估它的价值。$y^{\mathrm{DQN}}$ 中的 $\max_{a'}$ 会把估计噪声中的正偏差挑出来放大，从而使 $Q(s, a)$ 系统性高估。理解这一项是理解 Double DQN 改进的前提。

  • $y^{\mathrm{DQN}}$：普通 DQN 的目标值，作为监督在线网络学习的回归目标
  • $r$：执行动作后环境给出的即时奖励
  • $\gamma$：折扣因子，衡量未来奖励相对于即时奖励的重要性
  • $s'$：执行动作后环境转移到的下一状态
  • $a'$：下一状态下可供选择的候选动作
  • $\theta^-$：目标网络的参数，周期性地从在线网络复制得到

Double DQN 动作选择

$$a^* = \arg\max_{a'} Q(s', a'; \theta)$$

这一步只做选择，不做评估：用参数为 $\theta$ 的在线网络对下一状态 $s'$ 的全部候选动作打分，取分数最高的动作 $a^*$。由于选择者是在线网络，而评估者是目标网络，同一个动作不会因为被同一个网络高估而同时被选中和被高估。

  • $a^*$：在线网络在下一状态下选出的最优动作，只用于选择
  • $Q(s', a'; \theta)$：在线网络对下一状态下各候选动作的价值估计
  • $a'$：下一状态下可供选择的候选动作
  • $s'$：执行动作后环境转移到的下一状态
  • $\theta$：在线网络的参数，在训练中持续更新

Double DQN 目标值

$$y = r + \gamma Q(s', a^*; \theta^-)$$

这是 Double DQN 的核心目标值：先由在线网络选出 $a^*$，再由参数为 $\theta^-$ 的目标网络评估 $Q(s', a^*; \theta^-)$，并用折扣因子 $\gamma$ 折算后与即时奖励 $r$ 相加。若 $s'$ 为终止状态，则不存在未来价值，直接令 $y = r$。

  • $y$：解耦后的目标值，作为监督在线网络学习的回归目标
  • $r$：执行动作后环境给出的即时奖励
  • $\gamma$：折扣因子，衡量未来奖励相对于即时奖励的重要性
  • $s'$：执行动作后环境转移到的下一状态
  • $a^*$：在线网络在下一状态下选出的最优动作
  • $\theta^-$：目标网络的参数，周期性地从在线网络复制得到

小批量均方损失

$$L(\theta) = \frac{1}{B} \sum_{j=1}^{B} \left(y_j - Q(s_j, a_j; \theta)\right)^2$$

损失是小批量样本上目标值 $y_j$ 与在线网络预测 $Q(s_j, a_j; \theta)$ 之差的平方的平均值，批量大小为 $B$。对 $L(\theta)$ 关于 $\theta$ 求梯度并做梯度下降，就能让在线网络的预测逐步逼近解耦后的目标值 $y_j$，从而更新策略。

  • $L(\theta)$：小批量上的均方损失，用于衡量预测值与目标值的差距
  • $B$：从经验回放池中采样的小批量样本数量
  • $y_j$：小批量中第 $j$ 个样本的解耦目标值
  • $Q(s_j, a_j; \theta)$：在线网络对小批量中第 $j$ 个样本的状态动作对的价值预测
  • $s_j$：小批量中第 $j$ 个样本的当前状态
  • $a_j$：小批量中第 $j$ 个样本实际执行的动作
⑥ 数学推导

  1. 第一步，先看普通 DQN 为什么会高估：对下一状态 $s'$，目标网络给每个候选动作 $a'$ 一个带噪声的估计 $Q(s', a'; \theta^-)$，而最大值运算 $\max_{a'} Q(s', a'; \theta^-)$ 总倾向于挑中噪声为正的动作。

  2. 第二步，把这种偏差写成期望形式：即使每个动作的真实价值相同，只要估计有噪声，最大值的期望也会高于真实价值的最大值，偏差随动作数量和噪声增大而增大。

  3. 第三步，指出问题根源是选择与评估用了同一个量：同一个 $Q(s', a'; \theta^-)$ 既决定哪个动作最好，又决定它值多少钱，被高估的动作因此同时获得选中和加分。

  4. 第四步，引入解耦思想：让在线网络 $Q(s', a'; \theta)$ 负责选择，让目标网络 $Q(s', a^*; \theta^-)$ 负责评估，两者参数不同、更新节奏不同，被在线网络高估的动作不一定被目标网络高估。

  5. 第五步，写出选择公式：在线网络在 $s'$ 下取分数最高的动作作为 $a^*$。

    $$a^* = \arg\max_{a'} Q(s', a'; \theta)$$

  6. 第六步，写出评估与目标值：用目标网络评估被选中的 $a^*$，再按折扣因子 $\gamma$ 折算并加上即时奖励 $r$，得到解耦后的目标值 $y$。

    $$y = r + \gamma Q(s', a^*; \theta^-)$$

  7. 第七步，处理终止状态：若 $s'$ 是终止状态，则没有未来回报，直接令 $y = r$，不再做自举。

  8. 第八步，把目标值代入均方损失进行训练：对小批量中的每个样本 $j$，用 $y_j$ 监督在线网络的预测 $Q(s_j, a_j; \theta)$。

    $$L(\theta) = \frac{1}{B} \sum_{j=1}^{B} (y_j - Q(s_j, a_j; \theta))^2$$

  9. 第九步，给一个小数值例子：设 $r = 1$，$\gamma = 0.9$，在 $s'$ 下在线网络认为动作 $a_1$ 最好，即 $a^* = a_1$，而目标网络对 $a_1$ 的评估为 $Q(s', a_1; \theta^-) = 10$，对另一个被目标网络高估的动作 $a_2$ 的评估为 $Q(s', a_2; \theta^-) = 12$。

  10. 第十步，计算两种目标值并对比：Double DQN 只评估被选中的 $a_1$，得到 $y = 1 + 0.9 \times 10 = 10$；而普通 DQN 直接取目标网络的最大值，得到 $y = 1 + 0.9 \times 12 = 11.8$，后者把目标网络对 $a_2$ 的高估直接带进了目标值。

  11. 第十一步，总结效果与局限：解耦减轻了 $Q(s, a)$ 的系统性高估，使策略更稳定，但估计噪声本身仍未消失，因此仍需目标网络与经验回放来抑制自举带来的不稳定。

85import random
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
import gymnasium as gym
from collections import deque
# 超参数：CartPole 任务简单，网络与批量都可很小
GAMMA, LR, BATCH = 0.99, 1e-3, 64
BUFFER, SYNC_C, EPISODES = 10000, 100, 300
EPS, EPS_END, EPS_DECAY = 1.0, 0.05, 0.995

class QNet(nn.Module):
    """两层 MLP：输入状态，输出各动作的 Q 值"""
    def __init__(self, obs_dim, act_dim):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(obs_dim, 128), nn.ReLU(),
                                 nn.Linear(128, 128), nn.ReLU(), nn.Linear(128, act_dim))
    def forward(self, x):
        return self.net(x)

class Replay:
    """经验回放池：打乱时序相关性，稳定训练"""
    def __init__(self, cap):
        self.buf = deque(maxlen=cap)
    def push(self, *t):
        self.buf.append(t)
    def sample(self, n):
        return random.sample(self.buf, n)
    def __len__(self):
        return len(self.buf)

env = gym.make("CartPole-v1")
obs_dim, act_dim = env.observation_space.shape[0], env.action_space.n
online = QNet(obs_dim, act_dim)  # 在线网络：选动作、被训练
target = QNet(obs_dim, act_dim)  # 目标网络：只评估价值
target.load_state_dict(online.state_dict())  # 初始同步两个网络参数
opt = optim.Adam(online.parameters(), lr=LR)
memory, steps = Replay(BUFFER), 0

def act(state, eps):
    """epsilon-贪心：探索用随机动作，利用用在线网络贪心"""
    if random.random() < eps:
        return env.action_space.sample()
    with torch.no_grad():
        return online(torch.as_tensor(state, dtype=torch.float32)).argmax().item()

def learn():
    """Double DQN 核心：在线选动作，目标网络评估，解耦防高估"""
    if len(memory) < BATCH:
        return
    batch = memory.sample(BATCH)
    s, a, r, s2, d = map(np.array, zip(*batch))  # 末位为终止标志
    s_t = torch.as_tensor(s, dtype=torch.float32)
    a_t = torch.as_tensor(a, dtype=torch.int64).unsqueeze(1)
    r_t = torch.as_tensor(r, dtype=torch.float32)
    s2_t = torch.as_tensor(s2, dtype=torch.float32)
    d_t = torch.as_tensor(d, dtype=torch.float32)
    q = online(s_t).gather(1, a_t).squeeze(1)  # 取当前动作对应的预测值
    with torch.no_grad():
        # 关键：在线网络选动作，目标网络评估价值，避免既选又评
        a_star = online(s2_t).argmax(1, keepdim=True)
        q_next = target(s2_t).gather(1, a_star).squeeze(1)
        y = r_t + GAMMA * q_next * (1 - d_t)  # 终止时目标即奖励
    loss = nn.MSELoss()(q, y)  # 均方误差拟合目标
    opt.zero_grad(); loss.backward(); opt.step()

for ep in range(EPISODES):
    state, _ = env.reset(seed=ep)
    total = 0
    while True:
        action = act(state, EPS)
        next_state, reward, terminated, truncated, _ = env.step(action)
        done = terminated or truncated
        memory.push(state, action, reward, next_state, float(done))
        state, total, steps = next_state, total + reward, steps + 1
        learn()
        if steps % SYNC_C == 0:  # 定期同步目标网络
            target.load_state_dict(online.state_dict())
        if done:
            break
    EPS = max(EPS_END, EPS * EPS_DECAY)
    if (ep + 1) % 50 == 0:
        print(f"回合 {ep+1}: 奖励 {total:.0f}, epsilon {EPS:.3f}")
env.close()
⑨ 代码讲解
  1. 超参数与网络结构：代码开头用较小的网络与批量适配 CartPole，设 $\gamma=0.99$、学习率 $0.001$、批量 $64$；QNet 为两层 MLP，输入状态 $s$，输出各动作的 $Q(s, a; \theta)$，两个 $128$ 维隐藏层之间用 $\mathrm{ReLU}$ 激活，输出维度等于动作数。
  2. 经验回放池：Replay 用双端队列保存最近 $10000$ 条转移 $(s, a, r, s', d)$，其中 $d$ 为终止标志；push 存入、sample 随机抽取 $64$ 条，打破连续转移的相关性，让小批量更接近独立同分布，从而稳定 $Q$ 值的拟合。
  3. 双网络初始化：创建两个结构相同的网络，online 为在线网络，负责选动作并接受训练，target 为目标网络，只用于评估价值；二者参数分别记为 $\theta$ 与 $\theta^-$，初始时完全同步，之后 target 不直接训练，只在固定步数后从 online 复制参数。
  4. 动作选择：act 函数实现 $\epsilon$-贪心，探索时以概率 $\epsilon$ 随机采样动作，利用时先由 online 得到 $Q(s, a; \theta)$ 并取 $\arg\max_a Q(s, a; \theta)$；注意推理时关闭梯度，避免产生无谓的计算图。
  5. Double DQN 核心 learn：先判断回放池是否已有 $64$ 条样本，再随机取一批量并整理为状态 $s$、动作 $a$、奖励 $r$、下一状态 $s'$ 与终止标志 $d$；用 online 计算当前动作的预测值 $Q(s, a; \theta)$，关键一步是在不计算梯度的条件下，先由 online 选出 $a^*=\arg\max_{a'} Q(s', a'; \theta)$，再由 target 评估 $Q(s', a^*; \theta^-)$，得到目标 $y=r+\gamma Q(s', a^*; \theta^-)$，并用 $(1-d)$ 在终止时截断自举，即 $d=1$ 时 $y=r$；最后用均方误差拟合 $Q(s, a; \theta)$ 与 $y$，做一次梯度下降。
  6. 主训练循环：共 $300$ 回合，每回合从环境重置状态开始，用当前 $\epsilon$ 选动作、执行、把转移存入回放池、调用 learn 学习；每 $100$ 步同步一次 target，回合结束按 $\epsilon\leftarrow\max(0.05, 0.995\epsilon)$ 衰减探索率，每 $50$ 回合打印总奖励与 $\epsilon$，便于观察学习曲线。

⑪ 常见坑
  • 只改了选动作的网络、却忘了改评估网络：若 $a^*$ 与价值评估都用同一个网络，就退化为普通 DQN，仍会高估 $Q(s, a)$；检查 learn 中的关键两行，确认 $\arg\max$ 来自 online、而被 gather 的 $Q$ 值来自 target，两者不要写反或写成同一个网络。
  • 目标值参与了梯度计算：计算 $y$ 时必须关闭梯度或分离目标，否则 $Q(s', a^*; \theta^-)$ 也会被反向传播，目标随参数移动、训练不稳定；本代码用无梯度上下文包裹目标计算，改写时务必保留这一层，损失只对当前 $Q(s, a; \theta)$ 求梯度。
  • 终止标志用错或漏乘 $(1-d)$：若终止转移仍加上 $\gamma Q(s', a^*; \theta^-)$，相当于给已结束的回合凭空续上未来价值，$Q$ 值会被系统性抬高；同时注意区分 terminated 与 truncated，本代码把两者合并为 done 再转成 $d$，改环境时要确认 $d=1$ 的含义与奖励定义一致。
  • 同步周期与探索衰减调得极端：每步都同步 target 等价于没有目标网络，$Q$ 值容易震荡；$\epsilon$ 衰减过快则前期探索不足，奖励长期停在低位。调试时先固定同步周期为 $100$ 步、观察每 $50$ 回合的奖励是否上升，再单独调 $\epsilon$ 衰减或学习率，不要同时改多个超参数。
⑫ 练习题

练习题 1 请解释 DQN 的最大化偏差是如何产生的，并说明 Double DQN 是如何通过解耦动作选择与价值评估来减轻这一偏差的？请分别写出 DQN 与 Double DQN 在非终止转移下的目标值 $y$ 的计算公式，对比二者的区别，并结合本课数值例子说明 Double DQN 的目标值为何更低；最后说明 Double DQN 能否完全消除估计误差，为什么？

查看参考答案

核心在于：DQN 的目标同时用同一个网络完成动作选择与价值评估，估计噪声会被最大值运算放大；Double DQN 把这两件事分给两个不同的网络，从而减轻系统性高估。

1. 最大化偏差的来源

在 DQN 中，对非终止转移，目标值为 $y = r + \gamma \max_{a'} Q(s', a'; \theta^-)$，其中 $r$ 为即时奖励，$\gamma$ 为折扣因子，$s'$ 为下一状态，$a'$ 为下一状态的候选动作，$\theta^-$ 为目标网络参数。目标网络对每个 $a'$ 的估计都含有噪声，而 $\max_{a'}$ 运算总倾向于挑中噪声为正、被高估的动作。即使所有动作的真实价值相同，只要估计有噪声，$\max_{a'} Q(s', a'; \theta^-)$ 的期望也会高于真实价值的最大值，且偏差随动作数量增多和噪声增大而增大。于是被高估的动作同时获得“被选中”和“被加分”，$Q(s, a)$ 出现系统性高估，进而可能使策略偏向实际并不好的动作，训练也不稳定。

2. Double DQN 的解耦做法

Double DQN 把选择与评估分给两个参数不同、更新节奏不同的网络：用在线网络 $Q(s, a; \theta)$ 选择动作，用目标网络 $Q(s, a; \theta^-)$ 评估价值。具体分两步：先由在线网络选出最优动作 $a^* = \arg\max_{a'} Q(s', a'; \theta)$，再由目标网络评估该动作，得到目标值 $y = r + \gamma Q(s', a^*; \theta^-)$；若 $s'$ 为终止状态，则 $y = r$，不再自举。由于 $a^*$ 由 $\theta$ 决定，而价值由 $\theta^-$ 给出，被在线网络高估的动作不一定被目标网络高估，高估便不容易同时通过选择与评估两关，从而显著减轻偏差。

3. 数值对比

设 $r = 1$，$\gamma = 0.9$，在 $s'$ 下在线网络认为 $a_1$ 最好，即 $a^* = a_1$，目标网络的评估为 $Q(s', a_1; \theta^-) = 10$，而对另一动作 $a_2$ 的评估为 $Q(s', a_2; \theta^-) = 12$。Double DQN 只评估被选中的 $a_1$，得 $y = 1 + 0.9 \times 10 = 10$；普通 DQN 直接取目标网络的最大值，得 $y = 1 + 0.9 \times 12 = 11.8$。后者把目标网络对 $a_2$ 的高估直接带入目标值，前者则避免了这一点。训练时再用 $y$ 监督在线网络的预测，损失为 $L(\theta) = \frac{1}{B} \sum_{j=1}^{B} (y_j - Q(s_j, a_j; \theta))^2$，其中 $B$ 为小批量大小，$j$ 为样本编号。

4. 能否完全消除估计误差

不能。解耦只是让选择噪声与评估噪声不再完全同源，从而降低 $\max$ 运算带来的系统性正偏差，但估计噪声本身并未消失：在线网络与目标网络并非完全独立，目标网络是在线网络的周期性同步复制，$Q(s', a^*; \theta^-)$ 本身仍有噪声，自举、函数逼近和有限数据带来的误差仍在。因此 Double DQN 仍需经验回放、$\epsilon$-贪心探索、小批量梯度下降和周期性同步目标网络来抑制不稳定；它在已有 DQN 代码上只需改一行目标计算，即把 $\max_{a'} Q(s', a'; \theta^-)$ 改为先用在线网络求 $a^*$ 再用目标网络求 $Q(s', a^*; \theta^-)$，其余流程不变，但能得到更准确的 $Q(s, a)$ 估计、更稳定的训练和更好的策略。

练习题 2 已知一条非终止转移 $(s, a, r, s')$，其中即时奖励 $r = 1$，折扣因子 $\gamma = 0.95$，当前在线网络对已执行动作的预测值为 $Q(s, a; \theta) = 7$。在下一状态 $s'$ 下，在线网络 $Q(s', a'; \theta)$ 与目标网络 $Q(s', a'; \theta^-)$ 对三个候选动作的估计值如下表所示：

| 动作 | $Q(s', a'; \theta)$ | $Q(s', a'; \theta^-)$ | | $a_1$ | $12$ | $8$ | | $a_2$ | $10$ | $13$ | | $a_3$ | $9$ | $9$ |

请完成以下手算：（1）由在线网络确定 $a^*$；（2）分别计算普通 DQN 与 Double DQN 的目标值 $y$；（3）计算两种目标值的差值；（4）以 Double DQN 的目标值为监督，计算单样本均方损失 $L = (y - Q(s, a; \theta))^2$，并与用普通 DQN 目标值算出的损失作对比。最后用一句话说明计算结果如何体现 Double DQN 减轻最大化偏差的作用。

查看参考答案

第一步：确定 $a^*$。在线网络在 $s'$ 下的三个估计值为 $12$、$10$ 和 $9$，其中最大值为 $12$，对应动作 $a_1$，因此 $a^* = \arg\max_{a'} Q(s', a'; \theta) = a_1$。

第二步：计算普通 DQN 的目标值。目标网络在 $s'$ 下的三个估计值为 $8$、$13$ 和 $9$，其中最大值为 $13$，对应动作 $a_2$，即 $\max_{a'} Q(s', a'; \theta^-) = 13$。由于该转移非终止，普通 DQN 的目标值为 $y_{\text{DQN}} = r + \gamma \max_{a'} Q(s', a'; \theta^-) = 1 + 0.95 \times 13 = 1 + 12.35 = 13.35$。

第三步：计算 Double DQN 的目标值。由第一步得 $a^* = a_1$，目标网络对 $a_1$ 的评估为 $Q(s', a^*; \theta^-) = Q(s', a_1; \theta^-) = 8$，因此 $y_{\text{Double DQN}} = r + \gamma Q(s', a^*; \theta^-) = 1 + 0.95 \times 8 = 1 + 7.6 = 8.6$。

第四步：计算两种目标值的差值。$y_{\text{DQN}} - y_{\text{Double DQN}} = 13.35 - 8.6 = 4.75$，且 $13.35 \div 8.6 \approx 1.55$，即普通 DQN 的目标值比 Double DQN 高 $4.75$，约为后者的 $1.55$ 倍。

第五步：计算单样本均方损失。以 Double DQN 的目标值为监督，$L_{\text{Double DQN}} = (y_{\text{Double DQN}} - Q(s, a; \theta))^2 = (8.6 - 7)^2 = (1.6)^2 = 2.56$；以普通 DQN 的目标值为监督，$L_{\text{DQN}} = (y_{\text{DQN}} - Q(s, a; \theta))^2 = (13.35 - 7)^2 = (6.35)^2 = 40.3225$。两者损失之差为 $40.3225 - 2.56 = 37.7625$。

结论：普通 DQN 同时用目标网络选择 $a_2$ 并评估 $a_2$，把目标网络对 $a_2$ 的高估 $13$ 直接带入目标值；而 Double DQN 用在线网络选出 $a_1$ 后只评估 $a_1$，目标网络对 $a_1$ 的评估只有 $8$，因此目标值更低、损失也更小，这正体现了解耦选择与评估可以减轻最大化偏差，避免 $Q(s, a)$ 被系统性推高。最终数值：$y_{\text{DQN}} = 13.35$，$y_{\text{Double DQN}} = 8.6$，$L_{\text{Double DQN}} = 2.56$，$L_{\text{DQN}} = 40.3225$。

4. 预期现象

（1）下一状态价值均值：普通 DQN 一侧系统性更高。原因是普通 DQN 用同一个目标网络 $Q(s', a'; \theta^-)$ 既选动作又评估价值，$\max_{a'} Q(s', a'; \theta^-)$ 总倾向于挑中估计噪声为正的动作，把正噪声带进目标值 $y$；Double DQN 用在线网络 $Q(s', a'; \theta)$ 选出的 $a^*$ 再由目标网络评估，被在线网络高估的动作不一定被目标网络高估，因此目标值更低、更接近真实价值。

用本课数值例子可以定量验证这一点：设 $r = 1$，$\gamma = 0.9$，在线网络选出 $a^* = a_1$，目标网络的评估为 $Q(s', a_1; \theta^-) = 10$，而另一个动作的评估为 $Q(s', a_2; \theta^-) = 12$，则 Double DQN 的目标值为 $y = 1 + 0.9 \times 10 = 10$，普通 DQN 的目标值为 $y = 1 + 0.9 \times 12 = 11.8$，两者相差 $11.8 - 10 = 1.8$。在真实训练中，单个小批量的差值有正有负，但平均而言普通 DQN 的下一状态价值均值更高。

（2）回合回报曲线：Double DQN 一侧通常上升更快、波动更小，更容易稳定在高分段；普通 DQN 一侧上升更慢、曲线波动更大，学习后期也可能出现回报回落。这是因为被高估的目标值 $y$ 会通过均方损失 $L(\theta) = \frac{1}{B} \sum_{j=1}^{B} (y_j - Q(s_j, a_j; \theta))^2$ 反复抬高在线网络的预测值 $Q(s, a; \theta)$，使贪心策略建立在虚高的价值估计之上。

（3）差异大小的提醒：CartPole-v1 只有两个动作，即 $|\mathcal{A}| = 2$，动作越多、价值越接近时最大化偏差越大，因此在这个任务上两组差异可能不如多动作任务明显；同时训练本身有随机性，单次运行的曲线可能交叉。正确的做法是多次运行取平均，重点看下一状态价值均值曲线是否系统性分开，而不是只比较某一次的最终分数。

5. 一次满分不能否定 Double DQN

不能。最大化偏差说的是 $Q(s, a)$ 估计的统计性系统高估，不等于普通 DQN 每一次训练都必然失败；目标网络、经验回放和 $\epsilon$-贪心探索本身也能在一定程度上抑制不稳定，简单的 CartPole-v1 即使存在高估也可能被解出。一次偶然满分只是单次采样的结果，方差很大，不能推翻多次运行下目标值更低、曲线更稳定的平均趋势；Double DQN 的作用是减轻而非完全消除估计误差，这一点也与它仍需目标网络与经验回放配合使用是一致的。
