前置知识：Monte Carlo 方法

用下一步的估计更新当前估计，边走边学。

讲解视频 · 时序差分 TD 学习 · 4 分 16 秒

① 问题设定

在前几课中，我们已经知道策略评估的目标是估计给定策略 $\pi$ 下的状态价值 $V^\pi(s)$，即从状态 $s$ 出发按 $\pi$ 行动所能获得的期望折扣回报。动态规划需要已知的环境模型 $p(s', r \mid s, a)$，而 $MC$ 方法虽然不需要模型，却必须等到回合结束才能用完整回报 $G_t$ 更新价值，无法处理持续任务或很长的回合。$TD$ 学习要解决的正是这一问题：如何在不知道模型、也不必等到回合结束的情况下，从与环境的真实交互中在线估计 $V^\pi(s)$ 或动作价值 $Q^\pi(s, a)$。适用场景包括模型未知、回合很长或没有终止状态、需要边交互边学习的预测与控制任务，例如机器人导航、游戏与在线推荐等。输入为智能体与环境交互产生的每一步经验 $(s, a, r, s')$，以及折扣因子 $\gamma$ 与步长 $\alpha$；输出为逐步收敛的状态价值估计 $V(s)$ 或动作价值估计 $Q(s, a)$，进而可用于策略改进。

② 核心思想
  • 自举：用下一步价值估计 $V(s')$ 更新当前价值 $V(s)$，无需等到回合结束即可学习，这是 $TD$ 与 $MC$ 的根本区别。
  • $TD$ 误差 $\delta = r + \gamma V(s') - V(s)$ 衡量当前估计与一步目标之间的差距，是 $TD(0)$ 更新的驱动信号。
  • 在线增量更新：每经历一步经验 $(s, a, r, s')$ 就按 $V(s) \leftarrow V(s) + \alpha \delta$ 更新一次，适合持续任务与长回合。
  • 偏差与方差的权衡：$TD$ 目标依赖有偏的旧估计，偏差较大，但只用一步奖励，方差远小于依赖完整回报 $G_t$ 的 $MC$ 方法。
  • 可推广到控制与多步方法：同一思想可用于动作价值 $Q(s, a)$ 的 $SARSA$ 更新，也可通过资格迹把一步误差向过去多步传播。
③ 与已学方法对比

与动态规划相比，$TD$ 学习不需要已知的转移模型 $p(s', r \mid s, a)$，可以直接从真实交互经验中学习，因此适用于模型未知或难以建模的任务，但代价是只能通过采样逐步逼近 $V^\pi(s)$，收敛速度与稳定性不如基于模型的精确计算。与 $MC$ 方法相比，$TD$ 不必等到回合结束再用完整回报 $G_t$ 更新，可以在每一步后立即用 $V(s')$ 自举更新 $V(s)$，因而能处理持续任务、在线学习且方差更小；代价是目标本身依赖旧的估计，引入偏差，且对步长 $\alpha$ 的选择更敏感，若 $\alpha$ 过大容易震荡。总体上，$TD$ 在模型自由、在线性与方差之间取得了折中，是后续 $SARSA$ 与 $Q$ 学习等控制方法的基础。

④ 学习流程
  1. 观察初始化并观察状态将所有状态的 $V(s)$ 初始化为任意值，终止状态的 $V(s)$ 设为 $0$，随后观测回合的初始状态 $s$ 作为当前状态。
  2. 决策按策略选择动作在当前状态 $s$ 下，按待评估策略 $\pi$ 选择动作 $a$，输入为 $s$ 与 $\pi$，输出为待执行的 $a$。
  3. 行动执行动作并交互执行动作 $a$，与环境进行一步交互，输入为 $(s, a)$，输出为环境即将返回的奖励与下一状态。
  4. 反馈观测奖励与新状态观测环境返回的奖励 $r$ 与下一状态 $s'$，得到一步经验 $(s, a, r, s')$，输入为环境反馈，输出为该经验四元组。
  5. 计算计算 TD 误差用一步目标 $r + \gamma V(s')$ 与当前估计 $V(s)$ 作差，计算 $TD$ 误差 $\delta = r + \gamma V(s') - V(s)$，输入为 $(r, s', s)$，输出为 $\delta$。
  6. 更新更新状态价值沿 $TD$ 误差方向按步长 $\alpha$ 增量更新，$V(s) \leftarrow V(s) + \alpha \delta$，输入为 $V(s)$ 与 $\delta$，输出为更新后的 $V(s)$。
  7. 循环推进状态并循环令 $s \leftarrow s'$ 进入下一步；若回合未结束则回到选择动作继续学习，若 $V(s)$ 已收敛则停止，否则开始新回合。
⑤ 关键公式

TD 误差定义

$$\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$$

该公式把一步真实奖励 $R_{t+1}$ 加上折扣后的下一状态价值 $\gamma V(S_{t+1})$ 作为一步目标，再减去当前估计 $V(S_t)$，得到误差 $\delta_t$。当 $\delta_t$ 为正时，说明当前估计 $V(S_t)$ 偏低，需要上调；为负时则需要下调。它是 $TD(0)$ 更新的驱动信号，每一步经验都会先算出它再更新价值。

  • $\delta_t$：一步目标与当前估计之间的差距，正值表示当前估计偏低，负值表示偏高
  • $R_{t+1}$：执行动作后环境在下一步给出的即时奖励
  • $\gamma$：折扣因子，取值在 $0$ 到 $1$ 之间，用于折算下一状态价值
  • $V(S_{t+1})$：对下一状态价值的当前估计，即自举所用的旧估计
  • $V(S_t)$：对当前状态价值的当前估计，是本次要修正的对象

TD(0) 更新规则

$$V(S_t) \leftarrow V(S_t) + \alpha \delta_t$$

该公式是 $TD(0)$ 的核心更新式：每经历一步经验，就把当前估计 $V(S_t)$ 沿 $TD$ 误差 $\delta_t$ 的方向移动一小步，移动幅度由步长 $\alpha$ 控制。它不需要等到回合结束，也不需要环境模型，只用一步经验即可在线学习。反复更新后，$V(S_t)$ 会逐步逼近真实价值 $V^\pi(S_t)$。

  • $V(S_t)$：当前状态的价值估计，是本次更新的对象
  • $\alpha$：步长，取值在 $0$ 到 $1$ 之间，控制每步修正的幅度
  • $\delta_t$：本步的 $TD$ 误差，由一步奖励与下一状态价值算出
  • $S_t$：当前时刻所处的状态

SARSA 更新规则

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \big[ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) \big]$$

该公式把 $TD$ 思想推广到动作价值 $Q(S_t, A_t)$ 的控制问题：目标用下一状态实际执行的动作 $A_{t+1}$ 对应的 $Q(S_{t+1}, A_{t+1})$ 构成，而不是取最大值。更新后 $Q(S_t, A_t)$ 逐步逼近策略 $\pi$ 下的真实动作价值 $Q^\pi(S_t, A_t)$，再据此改进策略；因为更新用到 $(S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1})$ 五元组，所以称为 $SARSA$。

  • $Q(S_t, A_t)$：在状态 $S_t$ 下执行动作 $A_t$ 的动作价值估计
  • $\alpha$：步长，控制每步更新的幅度
  • $R_{t+1}$：执行动作后环境给出的即时奖励
  • $\gamma$：折扣因子，用于折算下一状态动作价值
  • $Q(S_{t+1}, A_{t+1})$：在下一状态 $S_{t+1}$ 下实际执行的下一动作 $A_{t+1}$ 对应的动作价值估计
  • $A_{t+1}$：在下一状态实际选择的下一动作，由 $\epsilon$ 贪心策略决定
⑥ 数学推导

  1. 从回报的定义出发：从时刻 $t$ 起的折扣回报 $G_t$ 是后续所有奖励的折扣和，它满足一步递推关系，即当前奖励加上折扣后的未来回报。

    $$G_t = R_{t+1} + \gamma G_{t+1}$$

  2. 对上式两边在策略 $\pi$ 下取期望，得到 $V^\pi(s)$ 的 $Bellman$ 期望方程，价值等于一步期望奖励加上折扣后的下一状态期望价值。

    $$V^\pi(s) = \mathbb{E}_\pi\left[R_{t+1} + \gamma V^\pi(S_{t+1}) \mid S_t = s\right]$$

  3. $MC$ 方法用一次完整采样的 $G_t$ 代替上式右边的期望，目标无偏，但必须等到回合结束，且 $G_t$ 包含多步随机奖励，方差很大。

  4. $TD$ 方法的自举思想是，不等 $G_{t+1}$ 的真实采样，而是用当前已有的估计 $V(S_{t+1})$ 代替它，构造只用一步真实奖励加一步旧估计的一步目标 $r + \gamma V(s')$。

  5. 一步目标与当前估计之差就是 $TD$ 误差，误差为正说明当前估计偏低，误差为负说明当前估计偏高。

    $$\delta = r + \gamma V(s') - V(s)$$

  6. 把误差乘以步长 $\alpha$ 加回当前估计，得到 $TD(0)$ 更新；$\alpha$ 越小学习越稳但越慢，$\alpha$ 越大修正越快但波动越大。

    $$V(s) \leftarrow V(s) + \alpha \delta$$

  7. 偏差与方差的权衡由此产生：一步目标依赖有偏的旧估计 $V(s')$，所以 $TD$ 目标有偏；但它只含一步真实奖励 $r$，不含后续多步随机性，所以方差远小于用完整 $G_t$ 的 $MC$ 方法。

  8. 数值例子：设当前 $V(s) = 0.5$，下一步 $V(s') = 1.0$，奖励 $r = 0$，折扣因子 $\gamma = 0.9$，步长 $\alpha = 0.1$。

  9. 先算一步目标为 $0 + 0.9 \times 1.0 = 0.9$，再算 $TD$ 误差 $\delta = 0.9 - 0.5 = 0.4$，说明当前估计低估了 $0.4$。

  10. 再按步长更新，$V(s) \leftarrow 0.5 + 0.1 \times 0.4 = 0.54$，只向目标移动了一小步；重复经历类似经验后，$V(s)$ 会逐步向 $0.9$ 附近收敛。

  11. 同一思想用于动作价值时，只需把 $V(s)$ 换成 $Q(s, a)$、把 $V(s')$ 换成下一状态实际动作对应的 $Q(s', a')$，即得到 $SARSA$ 更新；把一步误差沿轨迹向过去传播，则得到多步 $TD$ 与资格迹方法。

⑦ 伪代码

算法一：$TD(0)$ 策略评估

· 输入：待评估策略 $\pi$，步长 $\alpha$，折扣因子 $\gamma$
· 初始化：对所有状态 $s$，令 $V(s)$ 为任意值，终止状态的 $V(s)$ 为 $0$
· 输出：收敛后的状态价值估计 $V(s)$
· 重复以下过程，直至 $V(s)$ 收敛：
· 在每一回合开始时，观测初始状态 $s$
· 在回合未结束时重复以下步骤：
· 按策略 $\pi$ 在状态 $s$ 选择动作 $a$
· 执行动作 $a$，观测奖励 $r$ 与下一状态 $s'$
· 计算 $TD$ 误差 $\delta = r + \gamma V(s') - V(s)$
· 更新 $V(s) \leftarrow V(s) + \alpha \delta$
· 令 $s \leftarrow s'$

算法二：$SARSA$ 控制

· 输入：步长 $\alpha$，折扣因子 $\gamma$，探索参数 $\epsilon$
· 初始化：对所有状态 $s$ 与动作 $a$，令 $Q(s, a)$ 为任意值，终止状态的 $Q(s, a)$ 为 $0$
· 输出：收敛后的动作价值估计 $Q(s, a)$
· 重复以下过程，直至 $Q(s, a)$ 收敛：
· 在每一回合开始时，观测初始状态 $s$，并按 $\epsilon$ 贪心策略选择动作 $a$
· 在回合未结束时重复以下步骤：
· 执行动作 $a$，观测奖励 $r$ 与下一状态 $s'$
· 在状态 $s'$ 按 $\epsilon$ 贪心策略选择下一动作 $a'$
· 计算 $TD$ 误差 $\delta = r + \gamma Q(s', a') - Q(s, a)$
· 更新 $Q(s, a) \leftarrow Q(s, a) + \alpha \delta$
· 令 $s \leftarrow s'$，$a \leftarrow a'$

69import numpy as np

# 4x4 GridWorld：起点(0,0)，终点(3,3)奖励+1，每步-0.01，撞墙原地不动
ROWS, COLS = 4, 4
START, GOAL = (0, 0), (3, 3)
ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]  # 上、下、左、右
NAMES = ["↑", "↓", "←", "→"]

def step(s, a):
    """执行动作，返回 (r, s_next, done)：越界则留在原地"""
    r, c = s
    dr, dc = ACTIONS[a]
    nr, nc = min(max(r + dr, 0), ROWS - 1), min(max(c + dc, 0), COLS - 1)
    s_next = (nr, nc)
    if s_next == GOAL:
        return 1.0, s_next, True
    return -0.01, s_next, False

def epsilon_greedy(Q, s, eps):
    """eps-贪心：以 eps 概率随机探索，否则选 $Q$ 最大动作（探索是学到最优策略的关键）"""
    if np.random.rand() < eps:
        return np.random.randint(len(ACTIONS))
    return int(np.argmax(Q[s]))

def td0_evaluation(episodes=2000, alpha=0.1, gamma=0.99):
    """TD(0) 策略评估：评估均匀随机策略，每步用 $V(s')$ 自举更新 $V(s)$"""
    V = np.zeros((ROWS, COLS))
    for _ in range(episodes):
        s = START
        while True:
            a = np.random.randint(len(ACTIONS))  # 随机策略
            r, s_next, done = step(s, a)
            # $\delta$ 为 TD 误差：一步奖励加自举目标减当前估计，无需等回合结束
            delta = r + gamma * V[s_next] * (0 if done else 1) - V[s]
            V[s] += alpha * delta  # 在线增量更新：$V(s) \leftarrow V(s) + \alpha \delta$
            s = s_next
            if done:
                break
    return V

def sarsa_control(episodes=3000, alpha=0.1, gamma=0.99, eps=0.1):
    """SARSA 控制：同策略 TD 控制，用 $(s, a, r, s', a')$ 五元组更新 $Q(s, a)$"""
    Q = np.zeros((ROWS, COLS, len(ACTIONS)))
    for _ in range(episodes):
        s, a = START, epsilon_greedy(Q, START, eps)
        while True:
            r, s_next, done = step(s, a)
            a_next = epsilon_greedy(Q, s_next, eps) if not done else 0
            # 目标用下一动作的 $Q(s', a')$，而非最大值：SARSA 是同策略方法
            target = r + gamma * Q[s_next][a_next] * (0 if done else 1)
            delta = target - Q[s][a]
            Q[s][a] += alpha * delta
            s, a = s_next, a_next
            if done:
                break
    return Q

if __name__ == "__main__":
    np.random.seed(0)
    V = td0_evaluation()
    print("TD(0) 评估随机策略的状态价值：")
    print(np.round(V, 2))
    Q = sarsa_control()
    print("\nSARSA 学到的贪心策略（↑↓←→）：")
    policy = np.array([[NAMES[int(np.argmax(Q[r, c]))] for c in range(COLS)] for r in range(ROWS)])
    policy[GOAL] = "★"
    print("\n".join(" ".join(row) for row in policy))
    print("\nSARSA 的状态价值（每状态最大动作价值）：")
    print(np.round(Q.max(axis=2), 2))
⑨ 代码讲解
  1. 环境定义与转移函数：代码用 $4 \times 4$ 网格表示 GridWorld，起点为 $(0,0)$、终点为 $(3,3)$，动作只有上、下、左、右四种；`step` 先按动作计算新位置并用边界截断实现撞墙原地不动，到达终点返回奖励 $+1$ 并结束回合，否则返回 $-0.01$，返回值可理解为一步经验中的 $r$、$s'$ 与是否结束的标志 $done$。
  2. $\epsilon$贪心探索函数 `epsilon_greedy`：以概率 $\epsilon$ 随机选择动作进行探索，否则选择当前 $Q(s, a)$ 最大的动作进行利用；这一步只在 $SARSA$ 控制中使用，$TD(0)$ 评估使用均匀随机策略，因此不需要它。
  3. $TD(0)$ 策略评估 `td0_evaluation`：初始化 $V$ 为全零的 $4 \times 4$ 数组，每回合从起点出发、按均匀随机策略选动作；每步计算 $TD$ 误差 $\delta = r + \gamma V(s') - V(s)$，其中终点处 $V(s')$ 项乘以 $0$ 以消除自举，接着按 $V(s) \leftarrow V(s) + \alpha \delta$ 在线更新；与 $MC$ 方法不同，它不需要等到回合结束、拿到完整回报 $G_t$ 后才学习。
  4. $SARSA$ 控制 `sarsa_control`：初始化动作价值 $Q$ 为全零的 $4 \times 4 \times 4$ 数组，先用 $\epsilon$贪心选出初始动作 $a$；每步执行动作得到 $r$ 与 $s'$，再用 $\epsilon$贪心选出下一动作 $a'$，目标为 $r + \gamma Q(s', a')$，误差为 $\delta = r + \gamma Q(s', a') - Q(s, a)$，按 $Q(s, a) \leftarrow Q(s, a) + \alpha \delta$ 更新；关键在目标用实际执行的下一动作 $a'$ 而非最大值，因此是同策略方法。
  5. 主程序与结果解读：固定随机种子后先运行 $TD(0)$ 评估并打印 $V$，再运行 $SARSA$ 并对每个状态取 $\arg\max_a Q(s, a)$ 得到贪心策略，终点标为星号；同时打印 $Q$ 在每个状态上的最大值 $\max_a Q(s, a)$，可作为 $SARSA$ 学到的状态价值近似，用于检查策略是否沿最短路径走向终点。
⑩ 超参数
参数常用取值说明
学习率 $\alpha$$0.1$每步按 $V(s) \leftarrow V(s) + \alpha \delta$ 或 $Q(s, a) \leftarrow Q(s, a) + \alpha \delta$ 更新的步长；$\alpha$ 过大易震荡甚至发散，过小则 $V$ 与 $Q$ 收敛很慢，可先用 $0.1$ 再按需调小。
折扣因子 $\gamma$$0.99$决定未来奖励在目标 $r + \gamma V(s')$ 或 $r + \gamma Q(s', a')$ 中的权重；$\gamma$ 越接近 $1$ 越看重到达终点的 $+1$ 奖励，但 $TD$ 目标传播越慢，$\gamma$ 过小会使智能体只顾眼前的 $-0.01$ 惩罚而忽视终点。
探索率 $\epsilon$$0.1$仅用于 $SARSA$ 的 $\epsilon$贪心策略，以概率 $\epsilon$ 随机探索；$\epsilon$ 过大导致学到的 $Q(s, a)$ 被大量随机动作污染，过小则可能长期困在局部路径，常用 $0.1$，也可在训练后期逐步减小。
训练回合数 $episodes$$2000$ 或 $3000$$TD(0)$ 评估用 $2000$ 回合、$SARSA$ 控制用 $3000$ 回合；回合数不足时 $V$ 与 $Q$ 尚未收敛，策略仍可能绕路，判断标准是 $V$ 与贪心策略在增加回合后基本不再变化。
⑪ 常见坑
  • 忘记在终点截断自举项：若把目标写成 $r + \gamma V(s')$ 而不乘以 $0$，终点后的 $V(s')$ 会被错误计入，导致 $V$ 偏高且难以收敛；调试时打印终点那一步的 $\delta$，确认目标等于 $r$，并核对 `step` 返回的 $done$ 是否为真。
  • 把 $SARSA$ 误写成 $Q$ 学习：若把目标中的 $Q(s', a')$ 换成 $\max_a Q(s', a)$，就变成了异策略的 $Q$ 学习而非同策略 $SARSA$；调试时确认 $a'$ 是用 $\epsilon$贪心实际选出的下一动作，且 $Q(s, a)$ 的更新使用该 $a'$ 对应的值。
  • 学习率与探索率设置不当：$\alpha$ 过大时 $V$ 与 $Q$ 会在终点附近震荡，打印的价值表忽高忽低；$\epsilon$ 过大时策略长期随机、难以形成稳定路径。建议先固定 $\alpha=0.1$、$\epsilon=0.1$、$\gamma=0.99$，再逐个调参，并观察 $V$ 是否随回合数增加而趋稳。
  • 混淆评估与控制：`td0_evaluation` 评估的是均匀随机策略，其 $V$ 远低于最优价值，不能直接取 $\arg\max$ 得到最优策略；若想得到最优策略，必须运行 $SARSA$ 控制并从 $Q(s, a)$ 中提取贪心策略，检查时应比较随机策略与 $SARSA$ 策略的 $V$ 或 $\max_a Q(s, a)$。
  • 每回合忘记重置状态与动作：`td0_evaluation` 每回合必须把 $s$ 重置为起点，`sarsa_control` 每回合必须重新用 $\epsilon$贪心选出初始动作 $a$；否则智能体会从上一回合的终点继续走，$V$ 与 $Q$ 的更新分布被破坏，表现为价值表不对称或策略出现断裂。
⑫ 练习题

练习题 1 什么是时序差分 $TD$ 学习中的“自举”？请结合 $TD$ 误差 $\delta$ 与 $TD(0)$ 更新公式，说明 $TD$ 为什么无需等到回合结束就能学习，并解释它与 $MC$ 方法在学习目标、偏差与方差上的根本区别。

查看参考答案

自举是指在更新当前状态价值 $V(s)$ 时，不等待真实的未来回报，而是直接用下一步状态的已有价值估计 $V(s')$ 来构造学习目标。

从回报的定义 $G_t = R_{t+1} + \gamma G_{t+1}$ 出发，对其取期望可得 $Bellman$ 期望方程 $V^\pi(s) = \mathbb{E}_\pi\left[R_{t+1} + \gamma V^\pi(S_{t+1}) \mid S_t = s\right]$。$MC$ 方法用一次完整采样得到的 $G_t$ 代替上式右端，因此必须等到回合结束才能得到目标；而 $TD$ 方法用 $V(S_{t+1})$ 代替未知的 $G_{t+1}$，得到只含一步真实奖励的一步目标 $r + \gamma V(s')$。

两者之差就是 $TD$ 误差 $\delta = r + \gamma V(s') - V(s)$。若 $\delta > 0$，说明一步目标高于当前估计，即 $V(s)$ 被低估，应上调；若 $\delta < 0$，说明 $V(s)$ 被高估，应下调；若 $\delta = 0$，则当前估计与一步目标一致。

$TD(0)$ 更新为 $V(s) \leftarrow V(s) + \alpha \delta$，其中 $\alpha$ 为步长。$\alpha$ 越小，更新越稳但学习越慢；$\alpha$ 越大，修正越快但波动越大。每经历一步经验 $(s, a, r, s')$ 就可以立即计算 $\delta$ 并更新 $V(s)$，这就是在线增量学习，因此 $TD$ 适用于持续任务和很长的回合，而 $MC$ 必须等回合结束。

偏差与方差的权衡正在于此：$TD$ 的一步目标依赖旧估计 $V(s')$，而 $V(s')$ 本身未必等于真实价值 $V^\pi(s')$，所以 $TD$ 目标是有偏的；但它只含一步真实奖励 $r$，不含后续多步的随机奖励与随机转移，所以方差远小于 $MC$。相反，$MC$ 的目标 $G_t$ 是真实回报的一次无偏采样，偏差小，但它累积了整条轨迹的随机性，方差很大，且学习效率较低。

例如，设 $V(s) = 0.5$，$V(s') = 1.0$，$r = 0$，$\gamma = 0.9$，$\alpha = 0.1$，则一步目标为 $0 + 0.9 \times 1.0 = 0.9$，$TD$ 误差为 $\delta = 0.9 - 0.5 = 0.4$，更新后 $V(s) \leftarrow 0.5 + 0.1 \times 0.4 = 0.54$。可见 $V(s)$ 只向目标移动了一小步，多次经历类似经验后才会逐步逼近 $0.9$ 附近。

同一自举思想也可推广到控制：把 $V(s)$ 换成动作价值 $Q(s, a)$，把 $V(s')$ 换成下一状态实际动作对应的 $Q(s', a')$，就得到 $SARSA$ 更新；把一步误差沿轨迹向过去传播，则可得到多步 $TD$ 与资格迹方法。

总之，自举是 $TD$ 的核心：用旧估计 $V(s')$ 换取即时学习与低方差，代价是引入偏差；$MC$ 则用完整回报 $G_t$ 换取无偏性，代价是高方差与必须等待回合结束。

练习题 2 手算题：设折扣因子 $\gamma = 0.9$，步长 $\alpha = 0.1$，某策略下两个非终结状态 $s_0$ 和 $s_1$ 的初始价值估计分别为 $V(s_0) = 0.5$ 和 $V(s_1) = 0.8$，终结状态的价值规定为 $0$。智能体依次经历以下三步经验（每步都用 $TD(0)$ 更新，且后一步使用前一步更新后的价值）：（1）从 $s_0$ 出发，得到奖励 $r = 0$，转移到 $s_1$，$s_1$ 不是终结状态；（2）从 $s_1$ 出发，得到奖励 $r = 1$，转移到终结状态；（3）再次从 $s_0$ 出发，得到奖励 $r = 0$，转移到 $s_1$，$s_1$ 不是终结状态。请分别计算每一步的 $TD$ 目标 $r + \gamma V(s')$、$TD$ 误差 $\delta$ 和更新后的价值，并给出最终的 $V(s_0)$ 和 $V(s_1)$，同时简要说明第（3）步的目标与第（1）步相比为什么会发生变化。

查看参考答案

先写出 $TD(0)$ 的公式：$TD$ 目标为 $r + \gamma V(s')$，$TD$ 误差为 $\delta = r + \gamma V(s') - V(s)$，更新公式为 $V(s) \leftarrow V(s) + \alpha \delta$。其中终结状态的 $V(s')$ 取 $0$，即目标退化为 $r$。$\delta > 0$ 表示当前估计偏低，$\delta < 0$ 表示当前估计偏高，$\delta = 0$ 表示当前估计与一步目标一致。

第（1）步：当前 $V(s_0) = 0.5$，$V(s_1) = 0.8$，$r = 0$，$\gamma = 0.9$。$TD$ 目标为 $0 + 0.9 \times 0.8 = 0.72$；$TD$ 误差为 $\delta = 0.72 - 0.5 = 0.22$，为正说明 $V(s_0)$ 低估了 $0.22$；更新为 $V(s_0) \leftarrow 0.5 + 0.1 \times 0.22 = 0.5 + 0.022 = 0.522$。

第（2）步：当前 $V(s_1) = 0.8$，$r = 1$，$s'$ 为终结状态，故 $V(s') = 0$。$TD$ 目标为 $1 + 0.9 \times 0 = 1$；$TD$ 误差为 $\delta = 1 - 0.8 = 0.2$，为正说明 $V(s_1)$ 低估了 $0.2$；更新为 $V(s_1) \leftarrow 0.8 + 0.1 \times 0.2 = 0.8 + 0.02 = 0.82$。

第（3）步：此时已更新的 $V(s_0) = 0.522$，$V(s_1) = 0.82$，$r = 0$。$TD$ 目标为 $0 + 0.9 \times 0.82 = 0.738$；$TD$ 误差为 $\delta = 0.738 - 0.522 = 0.216$；更新为 $V(s_0) \leftarrow 0.522 + 0.1 \times 0.216 = 0.522 + 0.0216 = 0.5436$。

最终结果为 $V(s_0) = 0.5436$，$V(s_1) = 0.82$。第（3）步的目标由第（1）步的 $0.72$ 升为 $0.738$，因为第（2）步把 $V(s_1)$ 从 $0.8$ 提高到 $0.82$，而第（3）步的 $TD$ 目标依赖自举项 $\gamma V(s_1)$，所以 $s_1$ 价值的提高会经由自举向上传播到 $s_0$。这正是 $TD$ 无需等到回合结束、一步一步向后传播信息的体现；同时每步只按 $\alpha = 0.1$ 的比例向目标移动一小步，因此价值是逐步收敛而非一次跳到目标值。

1. 改动位置与改法

在 `sarsa_control()` 中复制一份并改名为 `q_learning_control()`，只改目标计算这一行。原来用下一时刻实际执行的动作 $a'$ 对应的 $Q(s', a')$ 做目标：

1target = r + gamma * Q[s_next][a_next] * (0 if done else 1)

改成用下一状态所有动作的最大动作价值做目标：

1target = r + gamma * np.max(Q[s_next]) * (0 if done else 1)

`a_next = epsilon_greedy(Q, s_next, eps) if not done else 0` 这一行保留，选出的 $a'$ 只作为下一步实际执行的行为动作，不再参与目标计算；`Q[s][a] += alpha * delta` 与终结时的乘子 $0$ 也不用改。

4. 改动后的公式

非终结状态的 $TD$ 目标由 $r + \gamma Q(s', a')$ 变为 $r + \gamma \max_{a'} Q(s', a')$，终结状态的目标仍为 $r$；$TD$ 误差变为 $\delta = r + \gamma \max_{a'} Q(s', a') - Q(s, a)$，更新仍为 $Q(s, a) \leftarrow Q(s, a) + \alpha \delta$。

5. 预期现象与解释

贪心策略方面，两者基本相同，都学到沿最短路向右或向下走向终点，因为最优路径本身没有变，差别主要不在策略箭头，而在价值大小。

价值方面，$Q$-learning 学到的每状态最大动作价值 $\max_a Q(s, a)$ 会系统性地高于 $SARSA$，且离终点越远差别往往越明显。原因是对同一张 $Q$ 表总有 $\max_{a'} Q(s', a') \ge Q(s', a')$，只有当 $a'$ 恰好是贪心动作时才取等号，所以 $Q$-learning 的 $TD$ 目标不低于 $SARSA$ 的 $TD$ 目标。更本质地说，$SARSA$ 估计的是会继续以 $\epsilon$ 概率随机探索的 $\epsilon$-贪心策略的价值，随机动作会带来额外的每步 $-0.01$ 奖励损失和撞墙原地不动，因此价值被拉低；而 $Q$-learning 的目标策略是贪心策略，它直接估计最优动作价值 $Q^*$，不受训练时探索动作的拖累。

收敛方面，在相同回合数 $3000$ 下，$Q$-learning 的价值通常更接近最优值，因为它的目标每一步都朝着最优方向自举，而 $SARSA$ 的目标会被实际执行的探索动作 $a'$ 拉低，需要更多经验才能把探索带来的低估抵消掉。
