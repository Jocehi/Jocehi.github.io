前置知识：Q-Learning、神经网络基础、经验回放概念

用神经网络拟合$Q$值，经验回放加目标网络稳定训练。

讲解视频 · DQN 深度 Q 网络 · 6 分 17 秒

① 问题设定

在第 5 课的表格 $Q$-Learning 中，智能体需要为每一个状态 $s$ 和动作 $a$ 维护一个 $Q(s, a)$ 的数值，并通过不断试错逼近最优动作价值函数 $Q^*(s, a)$。当状态是游戏画面、连续传感器读数或高维特征向量时，状态数量会爆炸甚至无限，表格既存不下也无法泛化到从未见过的相似状态，表格方法因此失效。DQN 要解决的正是这类高维、连续状态下的最优控制问题，其适用场景是：环境可建模为马尔可夫决策过程，智能体能反复与环境交互并获得奖励 $r$，动作空间是离散且有限的，状态可以表示为向量或图像等固定维度的输入。DQN 的输入是当前状态 $s$，例如一帧游戏画面或传感器向量；输出是该状态下所有离散动作的 $Q$ 值估计，即 $Q(s, a; \theta)$，其中 $\theta$ 为神经网络参数，智能体据此选择 $Q$ 值最大的动作执行。训练目标是让网络输出逼近满足贝尔曼最优方程的真实动作价值，从而在不需要环境模型的情况下学到近似最优策略。

② 核心思想
  • 用深度神经网络作为函数近似器，输入状态 $s$，输出所有动作的 $Q(s, a; \theta)$，从而把表格 $Q$ 值推广到高维连续状态。
  • 以贝尔曼最优方程构造 $TD$ 目标 $y = r + \gamma \max_{a'} Q(s', a'; \theta^{-})$，用当前网络预测与目标之间的均方误差作为损失进行训练。
  • 引入经验回放：把转移 $(s, a, r, s')$ 存入回放池，从中随机采样小批量数据训练，打破相邻样本的相关性并提高样本利用率。
  • 引入目标网络：用参数为 $\theta^{-}$ 的独立目标网络计算 $TD$ 目标，并每隔固定步数才把 $\theta$ 复制给 $\theta^{-}$，避免目标随网络更新而快速漂移。
  • 采用 $\epsilon$-贪心策略进行探索：以概率 $\epsilon$ 随机选择动作，以概率 $1 - \epsilon$ 选择当前 $Q$ 值最大的动作，在探索与利用之间取得平衡。
  • 通过随机梯度下降更新 $\theta$，最小化损失 $L(\theta) = \mathbb{E}[(y - Q(s, a; \theta))^2]$，使网络逐步逼近最优动作价值函数 $Q^*(s, a)$。
③ 与已学方法对比

与第 5 课的表格 $Q$-Learning 相比，DQN 最大的进步是把 $Q$ 值从表格换成神经网络，从而能处理图像与连续状态等高维输入，并泛化到相似的未见状态，这是表格方法因状态爆炸而无法做到的。与第 6 课的 $SARSA$ 相比，DQN 仍属于离策略学习，使用 $\max_{a'} Q(s', a'; \theta^{-})$ 构造目标而不是实际执行的下一个动作，因此可以复用历史数据，样本效率更高。代价是训练更不稳定：函数近似、自举与离策略三者结合容易带来发散风险，需要经验回放与目标网络来缓解；同时 DQN 需要大量交互样本，调参更复杂，只能处理离散动作，且神经网络训练的计算成本远高于查表更新。

④ 学习流程
  1. 观察初始化与观察初始化在线网络参数 $\theta$，令目标网络参数 $\theta^{-} = \theta$，创建容量为 $N$ 的经验回放池 $\mathcal{D}$，并从环境得到初始状态 $s$，在线网络输出该状态下所有动作的 $Q(s, a; \theta)$。
  2. 决策贪心选动作采用 $\epsilon$-贪心策略：以概率 $\epsilon$ 随机选择动作 $a$，以概率 $1 - \epsilon$ 选择当前 $Q$ 值最大的动作 $a = \arg\max_{a} Q(s, a; \theta)$。
  3. 行动执行动作在环境中执行动作 $a$，等待环境响应，为下一步接收奖励与新状态做准备。
  4. 反馈环境反馈环境返回奖励 $r$、下一状态 $s'$ 与终止标志 $d$，并将转移 $(s, a, r, s', d)$ 存入回放池 $\mathcal{D}$。
  5. 计算采样算目标从 $\mathcal{D}$ 中随机采样一小批转移，用目标网络计算 $TD$ 目标 $y = r + \gamma (1 - d) \max_{a'} Q(s', a'; \theta^{-})$，并计算均方损失 $L(\theta) = (y - Q(s, a; \theta))^2$ 的批量平均。
  6. 更新梯度更新参数用梯度下降更新在线网络，即 $\theta \leftarrow \theta - \alpha \nabla_{\theta} L(\theta)$，并每隔 $C$ 步令 $\theta^{-} = \theta$，把在线参数同步给目标网络。
  7. 循环循环下一轮令 $s = s'$，若 $d$ 为真则结束当前回合，否则回到第一步继续观察与决策，直至回合结束或达到最大步数。
⑤ 关键公式

贝尔曼最优方程

$$Q^*(s, a) = \mathbb{E}\left[r + \gamma \max_{a'} Q^*(s', a') \mid s, a\right]$$

这是 DQN 的理论出发点：最优动作价值 $Q^*(s, a)$ 等于当前奖励 $r$ 加上折扣后的下一状态最优价值 $\gamma \max_{a'} Q^*(s', a')$ 的期望。它把“现在做 $a$ 有多好”分解为“立即奖励”与“未来最优回报”两部分。DQN 的训练目标就是让神经网络逼近满足该方程的 $Q^*(s, a)$。

  • $Q^*(s, a)$：最优动作价值函数，表示在状态 $s$ 执行动作 $a$ 后按最优策略可获得的期望折扣回报。
  • $r$：执行动作 $a$ 后环境给出的即时奖励。
  • $\gamma$：折扣因子，取值在 $0$ 与 $1$ 之间，越接近 $1$ 越重视未来回报。
  • $s'$：执行动作 $a$ 后转移到的下一状态。
  • $a'$：在下一状态 $s'$ 下可选择的动作，取最大值时对应最优的下一动作。
  • $\mathbb{E}[\cdot \mid s, a]$：条件期望，表示对环境转移与奖励的不确定性求平均。

TD 目标（目标网络）

$$y = r + \gamma (1 - d) \max_{a'} Q(s', a'; \theta^{-})$$

这是用贝尔曼最优方程构造的单步 $TD$ 目标：把下一状态的最优价值估计 $\max_{a'} Q(s', a'; \theta^{-})$ 折扣后加上奖励 $r$，作为当前 $Q$ 值应逼近的监督信号。当 $d = 1$ 表示回合终止时，$(1 - d)$ 项会抹去未来价值，只保留 $r$。目标由参数冻结的目标网络 $\theta^{-}$ 计算，因此在一次更新内保持稳定。

  • $y$：单步 $TD$ 目标，即当前 $Q$ 值应逼近的监督信号。
  • $r$：即时奖励。
  • $\gamma$：折扣因子，控制未来价值在目标中的权重。
  • $d$：终止标志，$d = 1$ 表示回合终止，$d = 0$ 表示未终止。
  • $Q(s', a'; \theta^{-})$：目标网络对下一状态 $s'$ 下动作 $a'$ 的价值估计。
  • $\theta^{-}$：目标网络的参数，在固定步数内保持不变。

DQN 损失函数

$$L(\theta) = \mathbb{E}_{(s, a, r, s') \sim \mathcal{D}}\left[\left(y - Q(s, a; \theta)\right)^2\right]$$

损失是 $TD$ 目标 $y$ 与在线网络预测 $Q(s, a; \theta)$ 之差的平方在回放池 $\mathcal{D}$ 上的期望，衡量当前网络与贝尔曼目标的差距。对小批量样本取平均即可得到可计算的经验损失。最小化该损失等价于让网络输出不断向满足贝尔曼最优方程的方向移动。

  • $L(\theta)$：DQN 的损失函数，衡量网络预测与 $TD$ 目标之间的差距。
  • $\theta$：在线网络的待训练参数。
  • $y$：$TD$ 目标，由目标网络计算得到，在一次更新中视为常数。
  • $Q(s, a; \theta)$：在线网络对状态 $s$ 下动作 $a$ 的价值预测。
  • $\mathcal{D$：经验回放池，期望是对从 $\mathcal{D}$ 中随机采样的转移求平均。

梯度下降参数更新

$$\theta \leftarrow \theta - \alpha \nabla_{\theta} L(\theta)$$

这是 DQN 的参数更新规则：沿损失 $L(\theta)$ 关于 $\theta$ 的负梯度方向，以学习率 $\alpha$ 为步长调整网络参数。每做一次小批量更新，$Q(s, a; \theta)$ 就向 $TD$ 目标 $y$ 靠近一步。反复更新后，网络逐步逼近最优动作价值函数 $Q^*(s, a)$。

  • $\theta$：在线网络参数，更新后用于下一轮动作选择与价值预测。
  • $\alpha$：学习率，控制每次梯度更新的步长。
  • $\nabla_{\theta} L(\theta)$：损失 $L(\theta)$ 关于参数 $\theta$ 的梯度，指示损失上升最快的方向。
  • $L(\theta)$：DQN 的均方 $TD$ 损失。
⑥ 数学推导

  1. 从表格 $Q$-Learning 出发，最优动作价值 $Q^*(s, a)$ 应满足贝尔曼最优方程，即当前动作的价值等于即时奖励加上折扣后的未来最优价值。

  2. 当状态 $s$ 是高维图像或连续向量时，无法为每个 $s$ 建表，于是用神经网络 $Q(s, a; \theta)$ 近似 $Q^*(s, a)$，输入是 $s$，输出是全部离散动作的 $Q$ 值。

  3. 把近似函数代入贝尔曼最优方程，得到可计算的单步 $TD$ 目标，关键在于用独立的目标网络 $Q(s', a'; \theta^{-})$ 估计下一状态的价值，而不是用正在更新的在线网络。

    $$y = r + \gamma (1 - d) \max_{a'} Q(s', a'; \theta^{-})$$

  4. 若 $d = 1$，回合已终止，未来价值为 $0$，目标退化为 $y = r$；若 $d = 0$，则保留折扣的未来价值 $\gamma \max_{a'} Q(s', a'; \theta^{-})$。

  5. 定义 $TD$ 误差为目标与预测之差 $y - Q(s, a; \theta)$，对其平方并在回放池 $\mathcal{D}$ 中随机采样的小批量上取期望，就得到 DQN 的损失函数。

    $$L(\theta) = \mathbb{E}_{(s, a, r, s') \sim \mathcal{D}}\left[\left(y - Q(s, a; \theta)\right)^2\right]$$

  6. 经验回放的作用是把期望的分布从连续相关的轨迹换成回放池 $\mathcal{D}$ 中的均匀采样，从而打破相邻样本的相关性，并让同一条转移 $(s, a, r, s', d)$ 被多次利用。

  7. 目标网络 $\theta^{-}$ 在 $C$ 步内保持不变，使 $y$ 在一次更新中成为相对固定的监督信号，避免在线网络与目标同时漂移导致的训练不稳定。

  8. 对损失求关于 $\theta$ 的梯度并做一步随机梯度下降，更新规则为 $\theta \leftarrow \theta - \alpha \nabla_{\theta} L(\theta)$，这一步只改在线网络 $\theta$，不直接改 $\theta^{-}$。

  9. 每隔 $C$ 步执行一次 $\theta^{-} = \theta$，把学到的新参数同步给目标网络，再开始下一轮相对稳定的拟合，如此交替进行，网络逐步逼近 $Q^*(s, a)$。

  10. 数值例子：设某一步网络预测 $Q(s, a; \theta) = 1.0$，环境给出奖励 $r = 1$，下一状态的目标网络最大 $Q$ 值为 $\max_{a'} Q(s', a'; \theta^{-}) = 2.0$，折扣因子 $\gamma = 0.9$，且 $d = 0$，则目标为 $y = 1 + 0.9 \times 2.0 = 2.8$。

  11. 数值例子（续）：此时 $TD$ 误差为 $y - Q(s, a; \theta) = 2.8 - 1.0 = 1.8$，单个样本的损失为 $1.8^2 = 3.24$，梯度下降会沿减小损失的方向增大 $Q(s, a; \theta)$，使其向 $2.8$ 靠近；若该步是终止步 $d = 1$，则 $y = r = 1$，误差变为 $0$，无需再学习未来价值。

· 每隔 $C$ 步令 $\theta^{-} = \theta$

69import random
from collections import deque
import numpy as np, torch
import torch.nn as nn
import torch.optim as optim
import gymnasium as gym
GAMMA, LR, BATCH, BUFFER = 0.99, 1e-3, 64, 10000
EPS_START, EPS_END, EPS_DECAY = 1.0, 0.05, 0.99  # epsilon 衰减：探索逐渐转向利用
TARGET_UPDATE, EPISODES = 10, 200  # 每 10 回合同步目标网络，避免 TD 目标漂移
class QNetwork(nn.Module):
    """输入状态，输出所有动作的 Q(s,a;theta)"""
    def __init__(self, obs_dim, act_dim):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(obs_dim, 128), nn.ReLU(), nn.Linear(128, 128), nn.ReLU(), nn.Linear(128, act_dim))
    def forward(self, x):
        return self.net(x)
class ReplayBuffer:
    """经验回放：随机采样打破相邻样本相关性"""
    def __init__(self, capacity):
        self.buffer = deque(maxlen=capacity)
    def push(self, *t):
        self.buffer.append(t)
    def sample(self, batch):
        s, a, r, ns, d = zip(*random.sample(self.buffer, batch))
        return (np.array(s, np.float32), np.array(a), np.array(r, np.float32), np.array(ns, np.float32), np.array(d, np.float32))
    def __len__(self):
        return len(self.buffer)
def select_action(net, state, epsilon):
    # epsilon-贪心：小概率随机探索，大概率选 Q 最大动作
    if random.random() < epsilon:
        return random.randint(0, 1)
    with torch.no_grad():
        return int(torch.argmax(net(torch.tensor(state, dtype=torch.float32))).item())
def train_step(policy_net, target_net, optimizer, buffer):
    if len(buffer) < BATCH:
        return
    s, a, r, ns, d = buffer.sample(BATCH)
    s, ns = torch.tensor(s), torch.tensor(ns)
    a, r, d = torch.tensor(a), torch.tensor(r), torch.tensor(d)
    q = policy_net(s).gather(1, a.unsqueeze(1)).squeeze(1)  # 取执行动作的 Q(s,a;theta)
    with torch.no_grad():  # 目标网络不参与反传
        y = r + GAMMA * (1 - d) * target_net(ns).max(1)[0]  # TD 目标，终止时无后续价值
    loss = nn.MSELoss()(q, y)  # 最小化 (y-Q)^2，逼近贝尔曼最优方程
    optimizer.zero_grad(); loss.backward(); optimizer.step()
def main():
    env = gym.make("CartPole-v1")
    obs_dim, act_dim = env.observation_space.shape[0], env.action_space.n
    policy_net, target_net = QNetwork(obs_dim, act_dim), QNetwork(obs_dim, act_dim)
    target_net.load_state_dict(policy_net.state_dict())  # 初始 theta^- = theta
    optimizer = optim.Adam(policy_net.parameters(), lr=LR)
    buffer, epsilon = ReplayBuffer(BUFFER), EPS_START
    for episode in range(EPISODES):
        state, _ = env.reset(seed=episode)
        total_reward, done = 0, False
        while not done:
            action = select_action(policy_net, state, epsilon)
            next_state, reward, terminated, truncated, _ = env.step(action)
            done = terminated or truncated
            buffer.push(state, action, reward, next_state, float(done))
            train_step(policy_net, target_net, optimizer, buffer)
            state, total_reward = next_state, total_reward + reward
        epsilon = max(EPS_END, epsilon * EPS_DECAY)
        if (episode + 1) % TARGET_UPDATE == 0:
            target_net.load_state_dict(policy_net.state_dict())  # 定期硬同步目标网络
        if (episode + 1) % 50 == 0:
            print(f"回合 {episode + 1}: 总奖励 {total_reward:.0f}, epsilon={epsilon:.3f}")
    env.close()
if __name__ == "__main__":
    main()
⑨ 代码讲解
  1. 开头定义 $\gamma=0.99$、学习率 $1\times10^{-3}$、批量大小 $64$、回放池容量 $10000$，以及 $\epsilon$ 从 $1.0$ 衰减到 $0.05$、衰减系数 $0.99$、每 $10$ 个回合同步一次目标网络、共训练 $200$ 个回合。这些常量把 $TD$ 学习、探索与目标网络稳定的节奏固定下来，后续所有函数都引用它们，避免在循环中硬编码数值。
  2. `QNetwork` 是三层全连接网络：输入状态 $s$（对 `CartPole-v1` 为 $4$ 维），经两个 $128$ 维隐藏层与 $\mathrm{ReLU}$ 激活，输出 $2$ 个动作各自的 $Q(s, a; \theta)$。一次前向传播即可得到全部动作的价值，选动作时只需取 $\arg\max_a Q(s, a; \theta)$，这正是用函数近似替代表格 $Q$ 表、推广到连续状态 $s$ 的关键。
  3. `ReplayBuffer` 用 `deque` 实现容量为 $10000$ 的先进先出回放池，`push` 存入每一步的转移 $(s, a, r, s', d)$，其中 $d$ 表示是否终止；`sample` 用 `random.sample` 随机抽取 $64$ 条转移并转成 `numpy` 数组返回。随机采样打破了相邻转移在时间上的相关性，使小批量数据的分布更接近独立同分布，同时让同一条经验可被多次复用，提高样本效率。
  4. `select_action` 实现 $\epsilon$-贪心：以概率 $\epsilon$ 随机返回动作 $0$ 或 $1$ 进行探索，以概率 $1-\epsilon$ 在不计算梯度的情况下取当前 $Q(s, a; \theta)$ 最大的动作进行利用。`main` 中每回合结束令 $\epsilon$ 乘以 $0.99$，并用 $0.05$ 下限截断，即 $\epsilon \leftarrow \max(0.05, 0.99\epsilon)$，使探索随训练逐渐减少但不完全消失。
  5. `train_step` 是算法核心：先等回放池样本数不少于 $64$ 再训练；用 `policy_net` 对小批量状态 $s$ 取执行动作 $a$ 对应的 $Q(s, a; \theta)$，即 `gather` 操作；再用参数为 $\theta^{-}$ 的 `target_net` 在 `torch.no_grad()` 下计算 $TD$ 目标 $y = r + \gamma (1-d) \max_{a'} Q(s', a'; \theta^{-})$，其中终止时 $d=1$ 使后续价值为 $0$。最后以均方误差 $L(\theta) = \mathbb{E}[(y - Q(s, a; \theta))^2]$ 为损失，经 `optimizer.zero_grad()`、`loss.backward()` 与 `optimizer.step()` 更新 $\theta$，逐步逼近 $Q^*(s, a)$。
  6. `main` 创建 `CartPole-v1` 环境与两个结构相同的网络，初始令 $\theta^{-}=\theta$，用 $\mathrm{Adam}$ 优化器训练 `policy_net`；每回合先 `reset` 得到初始状态 $s$，循环中按 $\epsilon$-贪心选动作、执行 `env.step`、把 $(s, a, r, s', d)$ 存入回放池并调用 `train_step`，直到终止或截断；每 $10$ 回合把 $\theta$ 硬复制给 $\theta^{-}$，每 $50$ 回合打印总奖励与 $\epsilon$，用奖励是否接近 $500$ 判断学习效果。

⑪ 常见坑
  • 忘记处理终止状态：计算 $TD$ 目标时漏掉 $(1-d)$，会使终止状态 $s'$ 仍被赋予 $\gamma \max_{a'} Q(s', a'; \theta^{-})$ 的后续价值，导致 $Q(s, a; \theta)$ 被系统性高估；检查方法是让 $d=1$ 的样本单独计算 $y=r$，或在训练初期打印 $y$ 与 $r$ 的均值对比。
  • 目标网络与策略网络混用或漏加 `torch.no_grad()`：若用 `policy_net` 计算 $y$，或让 $y$ 参与反向传播，目标会随 $\theta$ 同步移动，相当于自己追自己，损失难以收敛；应始终用 `target_net` 计算 $y$ 并用 `torch.no_grad()` 包裹，且只在固定间隔把 $\theta$ 复制给 $\theta^{-}$，不要每步同步。
  • $\epsilon$ 衰减过快或回放池未预热：$\epsilon$ 在几十回合内就降到 $0.05$，或在回放池样本少于 $64$ 时仍期望有学习效果，都会导致早期探索不足、策略陷入局部最优；建议先检查打印的 $\epsilon$ 与总奖励曲线，前 $50$ 回合保持较高探索，并确认 `train_step` 在样本数不足 $64$ 时直接返回的逻辑没有被误删。
  • 学习率与 $Q$ 值爆炸：损失突然变大、$Q(s, a; \theta)$ 绝对值持续增大或出现 $\mathrm{NaN}$，多因学习率过高或 `gather` 索引错误导致取到错误的动作价值；调试时先把学习率降到 $10^{-4}$、打印每 $50$ 回合的损失均值与 $Q$ 均值，并核对动作 $a$ 的取值范围是否为 $0$ 或 $1$。
⑫ 练习题

练习题 1 与表格 $Q$-Learning 相比，为什么 DQN 不能只是把 $Q$ 表换成神经网络 $Q(s, a; \theta)$ 就直接训练？请结合 $TD$ 目标 $y$ 与损失 $L(\theta)$，说明经验回放和目标网络分别要解决什么不稳定因素，以及它们是如何起作用的。

查看参考答案

核心区别不在学习目标本身，而在用函数近似之后训练会变得不稳定。表格 $Q$-Learning 更新的是彼此相对独立的表项，而 DQN 要用同一个参数 $\theta$ 拟合所有 $s$ 和 $a$，一次更新会同时改变很多状态动作的 $Q$ 值。

DQN 的学习目标仍来自贝尔曼最优方程：用 $Q(s, a; \theta)$ 近似 $Q^*(s, a)$，并构造 $TD$ 目标 $y = r + \gamma (1 - d) \max_{a'} Q(s', a'; \theta^{-})$，其中 $r$ 为即时奖励，$\gamma$ 为折扣因子，$d$ 为终止标志，$s'$ 为下一状态，$\theta^{-}$ 为目标网络参数。损失为 $L(\theta) = \mathbb{E}_{(s, a, r, s') \sim \mathcal{D}}[(y - Q(s, a; \theta))^2]$，更新为 $\theta \leftarrow \theta - \alpha \nabla_{\theta} L(\theta)$。若 $d = 1$，则 $y = r$；若 $d = 0$，则保留 $\gamma \max_{a'} Q(s', a'; \theta^{-})$。

第一个不稳定因素是样本高度相关。智能体按轨迹连续收集 $(s, a, r, s', d)$，相邻样本几乎来自同一段轨迹，若按顺序做随机梯度下降，梯度会沿同一方向反复偏移，网络容易被近期数据带偏。经验回放把转移存入回放池 $\mathcal{D}$，再从中均匀随机采样小批量训练。这样做一是打破相邻样本的相关性，使小批量更接近独立同分布；二是同一条转移可被多次利用，提高样本利用率；三是训练分布不再完全由当前策略的最近轨迹决定，从而更稳定。

第二个不稳定因素是目标本身在动。如果用同一个在线网络同时计算预测 $Q(s, a; \theta)$ 和目标中的 $\max_{a'} Q(s', a'; \theta)$，那么每更新一次 $\theta$，$y$ 也会跟着变，相当于用自己不断移动的预测去监督自己，容易出现追逐自身、震荡甚至发散。目标网络把计算目标的参数固定为 $\theta^{-}$，在 $C$ 步内不更新，使 $y$ 在一次或一段更新中成为相对固定的监督信号；只有每隔 $C$ 步才执行 $\theta^{-} = \theta$，把已学到的参数同步过去，再开始下一轮稳定拟合。

此外，DQN 仍用 $\epsilon$-贪心在探索与利用之间平衡：以概率 $\epsilon$ 随机选动作，以概率 $1 - \epsilon$ 选当前 $Q$ 值最大的动作；$\epsilon$ 随训练衰减，探索逐渐转向利用。没有这一点，即使损失稳定下降，也可能只在已访问的区域内收敛到次优策略。

因此，DQN 不是简单替换，而是一套组合：神经网络解决高维状态的泛化，经验回放解决样本相关与低效，目标网络解决目标漂移，三者共同使 $Q(s, a; \theta)$ 能稳定逼近 $Q^*(s, a)$。

练习题 2 设折扣因子 $\gamma = 0.9$，从经验回放池 $\mathcal{D}$ 中随机采样得到一个包含三条转移 $(s, a, r, s', d)$ 的小批量。在线网络对已执行动作的预测值、环境奖励、目标网络在下一状态的最大 $Q$ 值，以及终止标志如下：

第一条转移：$Q(s_1, a_1; \theta) = 0.8$，$r_1 = 1$，$\max_{a'} Q(s_1', a'; \theta^{-}) = 2.5$，$d_1 = 0$； 第二条转移：$Q(s_2, a_2; \theta) = 1.2$，$r_2 = 0$，$\max_{a'} Q(s_2', a'; \theta^{-}) = 1.0$，$d_2 = 1$； 第三条转移：$Q(s_3, a_3; \theta) = 1.5$，$r_3 = -1$，$\max_{a'} Q(s_3', a'; \theta^{-}) = 2.0$，$d_3 = 0$。

第一，分别计算每条转移的 $TD$ 目标 $y_i$ 与 $TD$ 误差 $\delta_i = y_i - Q(s_i, a_i; \theta)$，其中 $y_i = r_i + \gamma (1 - d_i) \max_{a'} Q(s_i', a'; \theta^{-})$，$i = 1, 2, 3$。

第二，计算每条转移的单个样本损失 $(y_i - Q(s_i, a_i; \theta))^2$，以及该小批量的平均损失 $L(\theta) = \frac{1}{3} \sum_{i=1}^{3} (y_i - Q(s_i, a_i; \theta))^2$。

第三，若在计算第二条转移时错误地漏掉因子 $(1 - d_2)$，即误用 $y_2 = r_2 + \gamma \max_{a'} Q(s_2', a'; \theta^{-})$，计算错误的 $y_2$、$\delta_2$ 与单个样本损失，并与正确结果比较，说明漏掉 $(1 - d_2)$ 会带来什么问题。

查看参考答案

先写出单步 $TD$ 目标的计算公式：$y = r + \gamma (1 - d) \max_{a'} Q(s', a'; \theta^{-})$，以及 $TD$ 误差 $\delta = y - Q(s, a; \theta)$，单个样本损失为 $(y - Q(s, a; \theta))^2$。下面逐条计算。

第一条转移：$y_1 = r_1 + \gamma (1 - d_1) \max_{a'} Q(s_1', a'; \theta^{-}) = 1 + 0.9 \times (1 - 0) \times 2.5 = 1 + 0.9 \times 2.5 = 1 + 2.25 = 3.25$。于是 $TD$ 误差为 $\delta_1 = y_1 - Q(s_1, a_1; \theta) = 3.25 - 0.8 = 2.45$，单个样本损失为 $(y_1 - Q(s_1, a_1; \theta))^2 = 2.45^2 = 6.0025$。$\delta_1 > 0$ 说明在线网络低估了该动作的价值，梯度下降会增大 $Q(s_1, a_1; \theta)$，使其向 $3.25$ 靠近。

第二条转移：由于 $d_2 = 1$，回合已经终止，$(1 - d_2) = 0$，未来价值项被完全去掉，$y_2 = r_2 + \gamma (1 - d_2) \max_{a'} Q(s_2', a'; \theta^{-}) = 0 + 0.9 \times (1 - 1) \times 1.0 = 0 + 0 = 0$。于是 $\delta_2 = y_2 - Q(s_2, a_2; \theta) = 0 - 1.2 = -1.2$，单个样本损失为 $(y_2 - Q(s_2, a_2; \theta))^2 = (-1.2)^2 = 1.44$。$\delta_2 < 0$ 说明在线网络高估了该动作的价值，应减小 $Q(s_2, a_2; \theta)$，使其向 $0$ 靠近。

第三条转移：$y_3 = r_3 + \gamma (1 - d_3) \max_{a'} Q(s_3', a'; \theta^{-}) = -1 + 0.9 \times (1 - 0) \times 2.0 = -1 + 0.9 \times 2.0 = -1 + 1.8 = 0.8$。于是 $\delta_3 = y_3 - Q(s_3, a_3; \theta) = 0.8 - 1.5 = -0.7$，单个样本损失为 $(y_3 - Q(s_3, a_3; \theta))^2 = (-0.7)^2 = 0.49$。$\delta_3 < 0$ 同样说明在线网络高估了该动作的价值，应减小 $Q(s_3, a_3; \theta)$，使其向 $0.8$ 靠近。

小批量平均损失为 $L(\theta) = \frac{1}{3} (6.0025 + 1.44 + 0.49) = \frac{1}{3} \times 7.9325 = 2.644166\ldots \approx 2.64$。

若漏掉 $(1 - d_2)$，则错误的 $TD$ 目标为 $y_2^{\mathrm{wrong}} = r_2 + \gamma \max_{a'} Q(s_2', a'; \theta^{-}) = 0 + 0.9 \times 1.0 = 0.9$，错误的 $TD$ 误差为 $\delta_2^{\mathrm{wrong}} = y_2^{\mathrm{wrong}} - Q(s_2, a_2; \theta) = 0.9 - 1.2 = -0.3$，错误的单个样本损失为 $(y_2^{\mathrm{wrong}} - Q(s_2, a_2; \theta))^2 = (-0.3)^2 = 0.09$。与正确结果 $y_2 = 0$、$\delta_2 = -1.2$、损失 $1.44$ 相比，错误目标高估了 $0.9$，误差的绝对值由 $1.2$ 缩小为 $0.3$，损失由 $1.44$ 缩小为 $0.09$。这会使网络只把 $Q(s_2, a_2; \theta)$ 略微下调到 $0.9$ 附近，而不是正确地下调到 $0$ 附近，相当于为已经终止的状态虚构了并不存在的未来价值，造成 $Q$ 值高估，并且这种高估还会通过 $\max_{a'} Q(s', a'; \theta^{-})$ 传播到前面的状态。

最终结果：$y_1 = 3.25$，$\delta_1 = 2.45$，损失 $6.0025$；$y_2 = 0$，$\delta_2 = -1.2$，损失 $1.44$；$y_3 = 0.8$，$\delta_3 = -0.7$，损失 $0.49$；小批量平均损失 $L(\theta) \approx 2.64$。

练习题 3 基于本课 DQN 代码，把 `train_step` 中的 $TD$ 目标改造成 Double DQN。

本课代码的 `train_step` 函数中，$TD$ 目标是这样计算的：

1
2with torch.no_grad():
    y = r + GAMMA * (1 - d) * target_net(ns).max(1)[0]

即 $y = r + \gamma (1 - d) \max_{a'} Q(s', a'; \theta^{-})$，其中 $\gamma$ 为折扣因子，$d$ 为终止标志，$\theta^{-}$ 为目标网络参数。这一写法让同一个目标网络既负责在 $s'$ 处挑选使 $Q$ 值最大的动作，又负责评估该动作的价值，容易产生对 $Q$ 值的高估。

请把上述 $TD$ 目标的计算改造成 Double DQN：用在线网络 $Q(s', a'; \theta)$ 挑选下一动作 $a^* = \arg\max_{a'} Q(s', a'; \theta)$，再用目标网络 $Q(s', a'; \theta^{-})$ 评估该动作，即 $y = r + \gamma (1 - d) Q(s', a^*; \theta^{-})$。

要求： 1. 明确指出要改的是 `train_step` 中的哪几行，并给出改动前后的关键代码； 2. 简要说明这样改为什么能缓解高估，以及为什么不需要改动 $Q$ 网络结构、经验回放、损失函数 $L(\theta) = \mathbb{E}[(y - Q(s, a; \theta))^2]$ 和目标网络同步逻辑； 3. 在 `CartPole-v1` 上运行改造后的代码（超参数与原代码相同，`EPISODES = 200`），预测与原 DQN 相比，在 $TD$ 目标 $y$ 与 $Q$ 估计值、损失曲线和回合奖励曲线上会看到什么现象，并说明如何通过打印或记录平均 $y$ 来验证改造是否生效。

查看参考答案

1. 为什么原写法会高估

当目标网络对不同动作的 $Q$ 估计都带有噪声时，取 $\max$ 的操作总是倾向于挑到被高估的那个动作，即 $\mathbb{E}[\max_{a'} Q(s', a'; \theta^{-})] \ge \max_{a'} \mathbb{E}[Q(s', a'; \theta^{-})]$。在 `CartPole-v1` 中只有两个动作，两个动作的真实 $Q$ 值常常很接近，噪声更容易决定 $\max$ 的结果，于是 $y$ 会被系统性抬高，抬高的 $y$ 又通过损失 $L(\theta)$ 去抬高 $Q(s, a; \theta)$，形成自我强化的高估循环。

2. 改哪几行、改成什么

只改 `train_step` 中计算 $y$ 的一行，改为三行，其余代码不动：

1
2
3
4with torch.no_grad():
    next_actions = policy_net(ns).argmax(1, keepdim=True)  # 在线网络选动作
    next_q = target_net(ns).gather(1, next_actions).squeeze(1)  # 目标网络评估被选动作
    y = r + GAMMA * (1 - d) * next_q

`policy_net(ns)` 的输出为批量大小乘以动作数，`argmax(1, keepdim=True)` 得到每条样本选出的动作索引，`gather(1, next_actions)` 从目标网络输出中取出对应动作的 $Q$ 值，`squeeze(1)` 后与 $r$、$d$ 和 $q$ 的形状一致，可以直接用于计算 $y$。注意保留 `with torch.no_grad():`，因为 $y$ 是监督信号，不参与反传；取执行动作 $Q$ 值的 `q = policy_net(s).gather(1, a.unsqueeze(1)).squeeze(1)` 那一行和 `loss = nn.MSELoss()(q, y)` 那一行都不用改。

3. 为什么这样能缓解高估

改造后，$a^*$ 由在线网络参数 $\theta$ 选出，价值由目标网络参数 $\theta^{-}$ 评出，目标变为 $y = r + \gamma (1 - d) Q(s', a^*; \theta^{-})$，其中 $a^* = \arg\max_{a'} Q(s', a'; \theta)$。两套参数在同步间隔内并不相同，在线网络高估某个动作的噪声，不一定会被目标网络同样高估，因此高估不易被同一个网络同时放大。当 $\theta$ 与 $\theta^{-}$ 都逼近最优时，$a^*$ 趋于最优动作，目标仍趋于贝尔曼最优目标，因此改造没有改变最优解 $Q^*(s, a)$，只是改变了估计路径。

不需要改动的部分：$Q$ 网络结构仍是输入 $s$、输出全部动作的 $Q$ 值；经验回放仍采样 $(s, a, r, s', d)$；损失仍为 $L(\theta) = \mathbb{E}[(y - Q(s, a; \theta))^2]$；目标网络仍每隔 $10$ 回合同步一次，即 $\theta^{-} = \theta$，Double DQN 仍需要目标网络提供相对稳定的评估。

4. 预期现象

- $y$ 与 $Q$ 估计更保守：同一训练阶段打印的平均 $y$ 和平均 $Q(s, a; \theta)$，Double DQN 版本会系统性低于原版；$TD$ 误差 $\delta = y - Q(s, a; \theta)$ 的极端正值更少，损失 $L(\theta)$ 的尖峰更少、曲线更平滑。 - 回合奖励曲线更稳定：在 `CartPole-v1` 中每回合奖励等于坚持的步数，上限为 $500$。原版可能在后期出现奖励突然回落，Double DQN 版本后 $50$ 回合的平均奖励波动更小，更容易稳定在较高水平，但不保证每一次随机运行都更快收敛，因为回放采样仍有随机性。 - 计算量几乎不变：只多一次在 $ns$ 上对在线网络的前向计算，且在 `torch.no_grad()` 下进行，不增加反传和参数量，训练时间基本不变。

5. 常见改错与自查

- 若仍用 `target_net(ns).argmax(1)` 选动作，则与原版等价，毫无改进；若用 `policy_net(ns).max(1)[0]` 评估，则失去了目标网络的稳定作用，$y$ 会随 $\theta$ 快速漂移。 - 若 `argmax(1)` 不写 `keepdim=True`，`gather` 会因形状不匹配而报错；若忘记 `squeeze(1)`，$y$ 的形状与 $q$ 不一致，在 `nn.MSELoss()` 中可能被广播成错误的形状。 - 自查方法：在 `train_step` 中每隔若干步打印 `y.mean().item()` 与 `q.mean().item()`，与原版同阶段对比，Double DQN 版本的平均 $y$ 应系统性偏低，且奖励曲线的方差更小。
